# 羊圈布局与镜头范围修复

更新：2026-10-12（Asia/Shanghai）。本次仅补齐阶段 2 新增资产的挂载、布局与镜头范围，阶段 3 天气光效仍暂缓。

## 原问题与处理

`DrystoneWalls` 和 `HomesteadMeadow` 同时挂载 `SheepPen`，产生两份完全重合的羊圈、重复 SVG ID 和独立的门扇状态。现在只由 `HomesteadMeadow` 单独挂载，石墙组件仅绘制田界石墙。羊圈继续位于 1.0x 主舞台。

羊圈锚点从 `(990, 585)` 移到 `(975, 560)`，适度靠近草台东南侧，但整体占地留在草台外的草甸。实际 SVG 检查确认，泥土底坪与接触阴影均不与最外层草台羽化轮廓相交，最近距离约为 21.6 个场景单位，保留草地缓冲。位置和静态包络统一由 `landscapeLayout.ts` 所有；包络包括棚、围栏、开门状态、小羊和接触阴影，排除临时对白。删除了没有消费者、与实际门铰位置不一致的旧 `gateAnchor`。

`sceneExplorationBounds` 将羊圈包络与四个建筑的派生范围取并集，竖屏在 zoom 0.66 和 0.45 时均可通过拖拽完整查看羊圈。

按用户确认的布局原则，允许底部房间导航遮住部分羊圈，不以导航避让为理由把羊圈放到草台上。不测量导航遮挡带，也不根据导航尺寸重新约束镜头；原有视口留白和地形边界约束保持不变。导航可隐藏功能留待后续实现。

默认全景统一保留已验证的原相机 `(0, 135, 0.66)`，不为导航自动缩放或平移。短宽屏及竖屏可通过拖拽查看完整羊圈。房间焦点和建筑 placement 不变。

## 阶段 2 契约

天空、远山铁路和麦田的阻尼系数、`useLandscapeCoverage` 的动态地形裙边、地形曲线与主舞台物理坐标契约均未修改。新的镜头范围继续消费相同地形覆盖逻辑。
