## 小木屋

按用户对朝向的反馈，正面朝画面右下方（东南），进深退向左上方，左侧可见圆木侧墙。局部投影为 x=-44+u-0.62v，y=69.2-0.2u-0.4v-height，保持原占地中心。外墙、屋顶、地板、床、柜体和踏步消费同一基底，竖直构件保持直立。窗框和花箱处在可见的前墙面，保留原有粉、金、白、红、紫五种窗台花和垂挂绿叶。

恢复原资产的暖木卧榻质感：圆头床柱、木质床头与床尾板、陶土红羊毛厚被、深绿包边、绗缝针脚与蓬松软枕。床头在东侧，床头柜及单盏百褶阅读灯位于床头旁；人物床位偏移为 (-6.64,31.2)。墙面恢复圆木的凸起、端面年轮和暖木色，地基补充石块纹理。无室内火炉的烟囱、烟雾、柴棚及重复的柴堆移除；室内书架、热饮、门廊吊灯和零散小物简化，保留睡眠功能。

## 胶囊舱

按用户对变形的反馈恢复原资产的正视造型：舱体水平、舷窗为圆形，气密门、铭牌、顶部设备和四个支腿使用原来的局部几何。不再对侧面施加剪切矩阵，不再添加偏移后壳，人物也无需逆变换。保留黄铜舷窗、双色舱壳、气密门和复古设备；内部床铺和木格栅限于圆形开口，人物局部锚点为 (2,11)。

入口踏步在实体局部空间直接绘制，与水平门槛连接，踏步前缘保持水平。人物悬停标签位于舱内剪切区之外。

## 电波站与主屋地基

天线锅增加可见背壳和倾斜口沿，馈源沿向右上方的天空方向离开锅面，三根支架连接口沿与馈源。台面栏杆立柱按台面边缘推导高度，机柜的门窗与太阳能板格线符合所在面方向。观测人物、信号捕获和镜头共用原坐标契约。

主屋移除西侧的大团花境，改为三组较低、不规则的灌木与地被，在地板之后绘制。植被只覆盖少量柱脚，保留架空层、石脚、前廊台阶与入口。

## 朝向与风格修正后的验证

- `npm run lint`、`npm run build` 通过，27 项单元测试通过。
- 8 项相关非视觉浏览器检查通过：5 项房间导航、1 项键盘交互和 2 项场景坐标检查。覆盖 1200×800、1600×900、390×844 的主体可见性、快速切换、减少动态效果偏好与 resize；人物床位、建筑缩放和地面阴影随 placement 变化的检查通过。
- 11 张 Windows/Chromium 视觉基线随这次造型修正更新，并逐张复核。范围包含八处导航视角、深夜、静雨和空席。小木屋与胶囊舱两处近景另外通过不更新截图的基线对比。
- 生产构建在 4173 端口通过 7 项检查：八处导航与编辑保存、键盘交互，以及 5 项房间导航和响应式取景检查。
- 浏览器使用草台实际 Bézier 路径检查小木屋与胶囊舱的地基、踏步、支腿及地面阴影；1408 个边缘/顶点采样全部位于主体草台内部。检查不依赖外层模糊羽化来掩盖越界。

场景坐标回归检查人物、交互和相机随 placement 移动，并补充接地阴影与建筑共享变换的断言。矩阵断言比较六个实际系数，兼容浏览器返回缺少 `DOMMatrix.isIdentity` 属性的 SVGMatrix。生产预览配置改为只启动 4173 的单一服务，避免 `defineConfig` 多配置合并时同时继承开发服务。

## 窗后空间、屋檐与田界补充调整

移除床头柜右侧 u=74 的室内隔墙，后墙、地板、踢脚线和顶面延续至 u=126。正面窗墙和开口立柱保留，内部不再把花窗后的空间隔成封闭小间。窗框、五色花箱及床位锚点保持。

屋顶两坡与主屋共用 `terracottaRoof`，增设 7 单位厚的暖木封檐梁、深木底面和 3 单位厚的陶瓦边。木材配色沿用主屋的 `#5a3821`、`#492c19`、`#3b2314`，边缘有木色倒角与瓦缝。入口两级台阶分别为 6、7 单位厚，补齐侧面和立面；实体局部包围框 maxY 更新为 95。

原位置 (440,452) 的五杠牧场门移至东侧田界 (1176,178)，已有短矮石墙移至 (1230,196)，两者接续并共享 `YORKSHIRE_LAYOUT.drystoneWalls.eastWall` 的定位定义。门柱脚有轻接触阴影，保留门的悬停提示、键盘和点击交互；前廊不再被孤立栅栏占据。

用户标记 3 对应 `west-cottage-grounds` (−130,330)，是木框内叠放的小劈柴堆，旁边有紫色野花。这次只说明其用途，保留该装饰。

本轮验证：类型检查、生产构建和 27 项单元测试通过。正式应用的 10 张视觉基线与 6 项键盘/房间导航检查在生产预览上通过，包含 1200×800、1600×900、390×844 取景和 resize；开发专用的空席截图及 2 项场景坐标检查在开发入口通过。11 张最终视觉基线逐张复核。加厚后的小木屋地基和台阶共 520 个顶点/边缘采样均在草台实际曲线内，牧场门实体点击反馈正常。

开发页截图期间重新构建曾触发热更新，导致起居角的连续截图检查被刷新打断；生产预览中的同一检查通过。坐标与空席的 `/tests/fixtures/world.html` 页面不包含在生产构建中，不能对生产预览使用该定制入口。连续截图仍逐字节检查 PNG 相等，断言改用 Buffer.equals 的布尔结果，避免失败时输出庞大的二进制差异。
