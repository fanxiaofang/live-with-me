# 书架与咖啡黑胶柜的详细查看

更新：2026-10-12（Asia/Shanghai）。状态：实现与本地验证完成，等待用户体验反馈。第三阶段天空、天气及光效仍暂缓。

## 已确认范围

用户确认依次保留人物袍子、信箱柔和投影及书架完整细节；完善书架预览与场景的一致性、放大查看；以柜子作为新增详细查看的第一个范例。茶具、炉子、植物等组件的扩展等待柜子实际体验确认，椅子现有窗口保留。

本次没有删减共享资产的木纹、书脊、摆件和柜内物件，也没有修改投影滤镜、建筑布局、相机、地形覆盖或主题颜色。

## 书架

- `BookshelfModal` 接收与主场景相同的 resolved room layout，以及相同的林木借阅状态；书籍槽位和摆件的相对位置随已保存布局同步。
- `resolveBookshelfTiers` 保留原来的场景派生规则，并供预览、列表和选中详情共同使用。选中项按 ID 从当前数据重新解析，避免借出/归位后继续展示旧对象。
- 林木正在阅读《沙之书》时，预览与场景都显示借阅空位。该状态由人物活动决定，窗口不提供会与人物状态冲突的手动归位操作；其他藏书仍可手动抽出及归位。
- 当前完整 SVG 直接渲染在较大的查看区域中；支持 1～6 倍缩放、滚轮、双指缩放、拖动、方向键、＋／－及 Home。选中物件自动靠近，完整视图可随时恢复。
- 切换书架预设后恢复完整取景，清除不再存在的选中详情；现有新增藏书和预设功能保留。

## 柜子

- 普通模式点击柜体或台面/柜格物品可打开“咖啡与黑胶角”；SVG 入口支持 Enter / Space。
- 展示当前柜体与已保存物件位置，包括唱片机、摩卡壶、蜂蜜罐、咖啡豆和陶杯。查看窗口直接复用 `RecordCabinet`，不使用截图或另绘一套家具。
- 选择物件可聚焦并阅读简短描述，查看窗口与书架共用缩放、拖动和恢复完整视图的操作。
- 校准模式中的点击继续选择原有 Gizmo；普通查看不触发编辑，不写布局存储，也不改变主世界相机。
- 窗口按首次打开加载，关闭后不渲染预览 SVG。再次从场景打开时，按所点击的柜体或物件取景。

## 实现入口与保护边界

| 入口 | 职责 |
| --- | --- |
| `src/App.tsx` | 持有窗口开关与选中柜内物件，传递当前布局及人物借阅状态 |
| `src/components/bookshelf/Bookshelf.tsx` | 原始完整资产、书籍状态派生和物件标识 |
| `src/components/bookshelf/BookshelfModal.tsx` | 同步预览、当前列表/详情和既有藏书操作 |
| `src/components/cabinet/RecordCabinet.tsx` | 复用原始资产，区分查看与校准入口 |
| `src/components/cabinet/CabinetDetailModal.tsx` | 柜子查看窗口 |
| `src/components/inspection/SvgDetailView.tsx` | 独立 SVG viewBox，完整取景、物件聚焦及鼠标/触控/键盘操作 |
| `src/components/inspection/usePreviewSvgIds.ts` | 仅在预览边界隔离资产 ID 及资源引用，保护主场景 ID 和几何 |
| `src/shared/hooks/useDialogFocus.ts` | 窗口内键盘焦点、Escape 关闭及返回打开入口 |

预览复用的是完整资产和当前数据，只改变展示范围。`data-preview-item` 是稳定的物件定位标识，不保存坐标。预览的 ID 与本地 `url(#...)` 引用按实例隔离，并在子节点/相关属性更新时维护；主场景不经过此处理。后续扩展其它资产时，需要核对外部 defs、动态 ID 和专属交互，不能假设任意组件都可以直接放入查看窗口。
