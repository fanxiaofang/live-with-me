## 结论与范围

核对后确认：v3 的完整头部确实来自定稿 NW，问题在新画身体。后背到臀部外鼓，髋部与长垂袍摆转折呈拼接感，远侧袖子及手掌强调出不一致的肢体关系。因此本批不再迭代该长垂布构造，改用短而完整的安坐体块。

- **已实施：** 新 `nw-compact-seated-v4`，肩背、臀部和收拢双腿由一个闭合长袍外轮廓表达，腿前仅一条浅褶，不画分离的垂直小腿／悬挂袍片。袍摆收在坐面附近，有局部接触影；这是蒲团／沙发式的简化坐姿，不是参考图 3 的垂腿椅坐复刻，也不是打字动作。
- 定稿 NW 的完整头部、帽子、脸型、四发型及其源数据不变，只修改身体。近侧圆手放腿上，远侧手臂在这个角度被身体遮住，不再在后背上画第二只孤立圆手。工作状态耳机、配色及毛球选项沿用。
- 身体／入椅／实际房间继续共用 `WindsorSeatedCharacter`；原椅背覆盖靠背侧。结构辅助改为收腿参照，不再画旧伸展小腿与落地脚点。
- 原四视图、定稿四款 NW、人物五视图与完整装扮、原椅几何／尺寸／布局、第二席及书架保持原样。旧 v3 源另存 [before](before/)，旧截图／技术数据没有覆盖；用户三张图保留在本目录。
