## 实施

新增 `SofaWorkChair`、`SofaDeskCharacter`。通过 `FinalizedNwStandingCharacter` 复用定稿头部、肩背与上身，保持原始路径和统一倍率，仅整体平移 `(3,18)` 到椅内。裁掉不可见的站姿下半身和原垂手，单独绘制放在键盘上的袖臂和圆手。远臂位于靠背之前，近臂位于遮挡层之后；工作状态且键盘可达时使用实际键盘锚点，否则收手到扶手。校准参照共用相同的手部目标。

两个真实工位分别接入 A/B 试样，工位 ID、保存结构和所有坐标保持原样。检视窗口默认「沙发椅测试」，可切换两款、查看空椅/入椅、桌椅关系、双人样例；「原椅保留对比」和「温莎椅单人姿态」继续提供原组件及历史坐姿。旧温莎/复古椅坐稿的历史未通过状态不因本轮改变。

独立入口：`/sofa-chair-nw-review.html`，并提供两款空椅和入椅 SVG 下载。示例明确标为双人示意，不修改实际人物、席位或保存布局。独立页由 `npx tsx scripts/render-sofa-chair-study.tsx` 从同一生产组件生成，截图和导出同步更新。

## 验证与边界

- TypeScript 检查和 Vite 生产构建通过。
- `npx playwright test --config playwright.sofa-chair.config.ts`：1200px 和 390px 两项通过。
- 检查实际人物与预览使用同一 NW 源、同一手部位置；将键盘横移后，手心投影仍在实际键盘四边形内。
- 两款切换、双人样例/真实占用/空椅切换、原两款保留入口正常；预览 SVG 无重复 ID 或失效引用；无横向溢出、未捕获页面错误；保存布局和主场景相机未被预览修改。
- `two-chair-comparison.png`：两款空椅/人物并排；`desk-two-samples.png`：同一桌面的双人示意；`club-*.png`、`recliner-*.png`、`desk-*.png`：实际检视窗口截图。

技术通过仅说明接入与显示正常，不代表坐姿或家具造型已获认可。重点仍是参考图的沙发软包感、人物是否像坐在椅内、手臂是否自然，以及两款靠背的遮挡程度。未推进其它人物方向、天气或性能专项。
