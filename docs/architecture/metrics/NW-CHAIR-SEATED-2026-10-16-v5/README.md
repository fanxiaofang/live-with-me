## 已实施

- 新 `NwChairSeatedCharacter.tsx` 是独立完整人物，复用定稿 NW 的头部／脸型／帽子，另做肩背、骨盆、大腿、膝部、垂下袍摆、近侧袖和圆手。远侧手位保留在远腿上，由身体遮挡；没有打字或抬臂动作。工作状态耳机、当前配色和毛球选项沿用。
- `nwChairSeatedGeometry.ts` 将轮廓及控制点置于原椅的 u／v／高度坐标，通过现有 `chairPoint` 投影，臀部承托区与腿前袍摆分开定义。臀部承托范围 u=±4.2、v=-0.2…4.2，在原坐垫内；膝部向 -v 伸出，袍摆盖住小腿和脚并垂到近地处。这是二维资产的投影构造，不是布料模拟或已完成的人体物理验证。
- 同一闭合袍身从肩背经过大腿／膝部到下摆；仅少量浅褶和膝前明暗。接触影投影在坐面内，并裁到原坐垫轮廓；无遮挡身体不显示只有椅面才能承接的影子。袍底软影留在地面。原椅背的绘制、遮挡顺序及几何均保留。
- 新增独立原生矢量 **`public/character-shorthair-seated-nw-study.svg`**（13,024 字节），包含完整短发人物、透明背景，无位图／脚本。原坐姿四视图与站姿五视图不覆盖，未将未验收坐姿合入正式总表。制作／导出源为 `scripts/render-nw-chair-seated.tsx`。
- 原温莎椅只在经典短发时使用新稿；其余三发型仍保留旧稿，本批没有推广。检视窗口明确区分新短发稿和其它未通过旧稿，提供独立 SVG 下载。按需坐姿结构图和校准手位随对应姿态选择，不改家具摆放计算。
- 现用 **http://127.0.0.1:4178/** 保留地址、装扮与布局；无遮挡／入椅／实际房间复用同人同一袍身。新资源先复制、入口最后替换，被覆盖文件备份，详见 [publish.json](publish.json)。没有停止／重启 3000 或已有预览服务。
