# 三款新增 NW 发型：用户否定后的造型分析

2026-10-16 用户明确“其他三种发型均不合格，你自己分析下原因”。本轮仅放大核对既有原左侧/背面和新 NW，未修改任何人物、发型或椅子几何，未重跑产品测试或性能采样。

## 结论

三款均记为**已实施的失败试稿，用户视觉未通过，需重做发型结构**。用户本次没有对短发 SVG 转换追加确认，不能把三款否定解释为短发 SVG 已通过。此前认可范围仍是经典短发 v4 二维造型。

核心问题是制作方法没有完成原发型到 NW 的结构转换。短发由认可稿提取轮廓；其余三款在 `tools/character-nw-svg/hair.mjs` 中以绝对坐标重新拼绘，没有先明确发根、后枕体积、近远发束和扎点相对于同一头部的位置关系。名称、发色和局部符号保留了，但各发型的形态和空间关系没有保持。

## 分款观察

| 发型 | 原有识别特征 | 新 NW 的主要问题 |
| --- | --- | --- |
| 层叠长卷发 | 脸侧向内弯的短发束、后发逐层向外翻、沿肩背披落，侧面/背面均有发束转折 | 新后发是一整片近似居中的尖齿外轮廓，反复向外挑尖、内线却多为平行下弧，缺少成束卷曲与层间遮挡。近侧发束像从下颌旁垂出的细条；后发根部没有充分表达沿后脑绕过去的体积，发量/发长与原稿也缺少统一比例校准。整体更接近披片，未表达同一头发随头转向 NW。 |
| 偏分低束发 | 一侧长前发、另一侧耳后收拢，后枕发量连续汇向后颈低扎点，只有一束短尾；原设定左右不对称 | 新稿把面前长发画短、画窄，脸侧出现零散灰条；帽下绕后脑到扎点的灰色体块没有连续成立，中间露出不合理的大片皮肤，局部细灰片穿到脸/颈旁。扎点仍靠画面最右侧，缺少随 NW 转向后的后脑定位，发尾像挂在领旁。前发、后发、扎点未读成同一束头发。 |
| 双色蓬松碎发 | 浅色层有长短错落的前发和侧向外翘发梢；后颈为独立深色短底发，两层有不同方向和长度 | 新浅色层被压成沿帽檐的窄带，尖角密集、大小/间距/朝向过于均匀；深色底层也排成规则尖齿。主要体积和宽窄变化不足，鬓侧与后颈的层次分区弱，原先蓬松羽状的发束读成两条锯齿边。颜色层次存在，发型特征不足。 |

## 共用底形与遮挡的错误

共用身体、头型、帽子及位置是合理的；不能因此固定成短发的可见皮肤与后颈关系。当前 `reference-contours.json` 的 `skinBase` 来自短发可见脸部及短后发区域的补形，生成器主要按“后发 → 皮肤底形 → 前发 → 帽子”叠放。这种分组不足以表达三款的后枕外层、近侧覆盖、远侧收缩及后颈集束。

结果是：部分后发被皮肤底形压住后，只靠细前发修补；另一些发片直接铺在脸侧。低束发的连续收拢体积因此最容易被切碎。正确约束应是保留已认可的头部/脸部基础曲线和位置，让每款头发按原设定产生自己的遮挡，不能把“共用头型”误作“共用露肤区域”。

## 交付判断失误

上一批的不透明轮廓交并比、脸部边缘偏差只衡量**短发 SVG 与认可二维稿**，未衡量另外三款是否保留原发型身份、正确表达 NW。解析、透明度和共用头部位置检查不能回答这个造型问题。一次画完三款而没有先把一款的转向关系做成立，放大了相同方法的错误。

下一次修正应先只处理层叠长卷发的 NW 头肩：固定已认可头型/帽子/位置，从原侧面与背面确定后枕发量、主要发束根部与长度，再建立近远侧轮廓及内外卷曲，少量内线最后补。该一款通过后，再分别处理低束发的连续收束/扎点和碎发的两层体积与疏密。本次只分析，不继续改图，不恢复性能或其它专项。
