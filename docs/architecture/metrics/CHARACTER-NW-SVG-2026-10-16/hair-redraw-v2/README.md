# 三款 NW 发型第二轮重绘

日期：2026-10-16。用户在原因分析后明确要求「根据你分析的原因对 3 款发型重做一次」。本轮按卷发 → 低束发 → 双色碎发逐款绘制和看图，完成三款，不将此前“下次先只做一款”的建议当作新的授权限制。

## 已实施

- **层叠长卷发**：后脑表面覆盖皮肤底形，消除帽下后脑露肤空隙；脸侧两段内卷与后侧外翻分开，肩背长发改为有重叠和转折的宽发束，底端长短不齐。检查放大图后删除越出外轮廓的细线。
- **偏分低束发**：原左侧为耳后收拢侧，右侧长前发在本方向处于远侧；长前发在皮肤后绘制，恢复长度。近侧至后枕为一个连续发体，收向 `(625,608)` 的后颈扎点，同处连接一束短尾，删除穿过脸颈的零散补片。
- **双色碎发**：浅色层加宽发束、拉开长度差，前侧短梢与较长鬓侧发束、后侧外翘分区；深色层覆盖后脑并落在后颈，避免被皮肤底形切碎。保持既有浅金/深色配色。
- 更新原入口 `/character-standing-nw-svg-review.html` 和无版本短发审阅入口，首先展示三款头肩，再展示同身比例及逐款原左侧 / 新 NW / 原背面，旧失败稿可展开对照。
- 修改前的四张 NW SVG、发型源、构建/审阅脚本和审阅 HTML 在 [before](before/)；[before-files.json](before-files.json) 保存原哈希。第一批原始测量、截图和失败分析未覆盖。本轮产物哈希独立在 [assets.json](assets.json)。

绘制层次：`hair.mjs` 的 `back` 只放被脸遮挡的远侧头发；`front` 按后脑可见表面 → 近侧发束叠放，最后由共用帽子遮住发根。头后侧的头发不能全部放在皮肤后面。各款共用原脸部底形，但可见皮肤区域随发型遮挡改变。

制作与检查入口：

```powershell
node scripts/build-character-nw-svg.mjs
node scripts/inspect-nw-hair-redraw.mjs
node scripts/review-character-nw-svg.mjs
```

构建可追加 `curly` / `sidepart` / `shaggy` 只重建指定资产；完整交付用无参数构建写入四款清单。显示检查使用已有本地 4181 服务，无新依赖。
