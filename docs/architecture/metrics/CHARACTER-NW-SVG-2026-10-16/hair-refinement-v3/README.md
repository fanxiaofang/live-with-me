# NW 发型第三轮：按完整四视图局部修订

日期：2026-10-16。用户反馈第二轮卷发左侧纹理更密且缺少侧边碎发，低束发偏分长前发位置不对；双色碎发“勉强合格”，但侧面过密、长度均匀。该评价不记成三款最终验收。

## 四视图评价及本轮实施

| 发型 | 原正、左、背、右四图的约束 | 第二轮问题 | 本轮修改 |
| --- | --- | --- | --- |
| 长卷发 | 正面/两侧帽檐下有独立短发梢；后发以少量、分开的弧线表示转折，侧边内卷与后侧外翻并存 | 左半边闭合发片边界与长纹理线重复叠加，密度明显高于原稿；帽下侧面短发梢缺失 | 合并后发主轮廓，去掉重复片界和长线，仅留三段分开的内部转折线；保留脸侧内卷，并补两处帽下短碎发 |
| 偏分低束发 | 原正面长前发属于人物右侧；左侧为耳后收拢侧，右侧才展示完整主发片；背面主要显示低扎束 | 将远侧前发画在额头最外沿，露出一整片前帘，原侧面关系没有随背左斜角收缩 | 将远侧发根向脸后收回，由同一脸部底形遮挡，仅露出窄幅下段；后枕、扎点及单束尾保留，未改变原左右身份 |
| 双色碎发 | 正面/侧面是长短交替的疏密发束；背面保留浅金上层和深色后颈 | 侧边发梢仍近似沿帽檐等距排布，长度节奏不足 | 合并部分细小侧束，错开较长鬓束与短束，减少侧面内部线条；保留第二轮主体、后侧外翘和深色底层 |
