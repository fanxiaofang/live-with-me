# 已验收草甸组合接入正式场景

2026-10-20，按用户“最后一轮的场景组合直接接入项目中”要求，将第九轮组合设为正式默认。打开项目首页即可查看，无需实验查询参数。

## 正式组件

源码均位于 `src/components/scenery/yorkshire/vegetation/`，不依赖 `tests/fixtures`：

- `HomesteadMeadowSurface.tsx`：三层宽范围综合色差，保持第八／九轮覆盖强度 0.8，无草刷／草痕。
- `HomesteadMeadowPlanting.tsx`：36 个草簇、5 处极轻根部压暗、2 处台阶使用痕迹。
- `meadowPlantingLayout.ts`：合并原逐轮叠加组件为一份静态布局数据，跟随主屋、小屋、睡眠舱和大树锚点。
- `LocalMeadowPlanting.tsx`：蜂箱两处野花混生簇＋两处短草落点，及主屋四处石缝短草替换。
- `meadowPalette.ts`：共享午后／夜晚／雨天配色。
- `MeadowVegetationAssets.tsx`：沿用已保留三组资产的原子形态，源码与透明 SVG 校验值保持不变。

`ThreeWorld` 默认使用该组合；主屋现有灌木、绣球、地被、建筑、交互及场景主布局保持原样。蜂箱花草在原箱体局部地面层绘制，保持箱体遮挡及入口空隙；庭院草簇在建筑和树之前的地面装饰层绘制；石缝短草在主屋原局部坐标中接续。
