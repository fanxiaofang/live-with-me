# 蜂箱花草重组与庭院草形统一

2026-10-19 用户暂时验收当前方案，作为当前场景组合基准保留。以第八轮为基础的局部植被组合已于 2026-10-20 接入正式入口，见[集成记录](../integration/README.md)。以下保留原试放与当时的验证记录。此次允许在蜂箱区域使用野花；草台与主屋前院不新增野花。

## 本轮内容

### 蜂箱

替换原蜂箱细线草、两处独立通用花点、亮紫花穗组，以两处非对称低矮野花混生簇加两处短草落点重组：

- 左侧：红三叶草 + 雏菊 + 一簇贴地草。
- 右后侧：少量毛茛 + 较弱三叶草 + 一簇短草。
- 两处外围短草落点，其中左侧是一强一弱双簇，右侧为弱单簇。

共 4 株野花（各自保留独立叶丛／复叶／分枝结构）、5 个短草小簇。使用此前 v2 的原生 SVG 植物形态，灰粉紫、乳白、柔黄配木屋和蜂箱暖木色；夜晚、雨天沿用已有植物配色规则。没有恢复高草托大花，也不围绕蜂箱均匀布置。

箱体、屋顶、支架、接地阴影与蜜蜂保留。植被插槽位于现有蜂箱局部地面坐标中、箱体之前，自动继承小屋布局，不重复硬编码世界坐标；新植物避开箱体和右前方飞行／取用空间。

### 主屋边缘

保留现有灌木、绣球、台阶花草和建筑边缘地被大形，包括 `cottage-ground-planting` 与 `foundation-greenery`。没有用草模板替换灌木。

零散草统一的第一批仅替换 `gravel-verge-grass` 的四处细线草，使用很小的短草／交织草剪影，原位置轻微协调，不新增前院散点。主屋局部插槽继承房屋布局，保持装饰不接管指针。其余基础边缘草、远处牧草地和其它物件周边植被暂保留，避免一轮全场替换。

### 草台

第八轮综合色差强度、36 个草簇、5 处根部轻压暗、2 处台阶使用痕迹均沿用。

## 对照

[index.html](index.html) 默认“木屋与蜂箱”视角，另可切总览和主屋前院。支持同镜头查看第八轮／本轮重组，以及蜂箱、石缝草两个独立开关。

关闭某项时恢复原植被，而非把该区域清空；原节点仅在对应本轮替换生效时隐藏。旧轮次预览和截图保留。

- 正式入口未挂载本轮实验，原蜂箱花草仍可见。
