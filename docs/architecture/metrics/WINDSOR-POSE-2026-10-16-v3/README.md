## 已实施

- 原 `WindsorSeatedHead` 不再拼用原背面发型，改用定稿 NW 原生 SVG 的完整头部路径。`generate-windsor-nw-head.mjs` 读取定稿快照、核对 SHA256，生成 `nwSeatedHeadAssets.ts`。默认帽型、脸部底形、发型的所有路径 `d` 与定稿文件逐项一致，只对整个头部统一缩放、平移以放到坐姿领口，不旋转或局部挪动头发。
- 头部缩放保持 NW 对照稿的 `0.039734395750332004`，围绕同一源坐标中心 `(545,390)` 装配。颜色参数及实例 ID 独立处理，保留角色肤色/帽色/发色；无毛球选项只替换帽顶相应弧段，默认毛球开启仍用定稿完整帽型。耳机适配新头部的位置。
- 长袍为一个连续闭合轮廓，从肩背到坐面承托的髋部，向桌面方向铺过大腿/膝部，再垂至遮脚下摆。减弱原髋部转折的拼片感，少量浅褶表示松量。袖子自然下垂，前臂及圆手搭在腿上，键盘和状态不抬手。
- 身体与原椅子独立：坐垫先画，人物在坐垫上，原椅背后画并覆盖靠背一侧。原椅形、尺寸、摆放和第二席实现均未改动。前向仍是原椅的 `-v`（屏幕左上），肩/髋/膝横轴均沿原 `u` 轴；原四图方向契约不变。
- 更新原“温莎椅单人姿态”的说明，同一人物、同一几何用于两张独立图和真实占用。没有占用时，窗口明确为参考人物，房间保持空椅。
