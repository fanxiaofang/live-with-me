# F3 大气透视、分层与连续性专项总结

更新：2026-11-21。本文是专项当前状态的统一入口，替代逐轮叠加的计划与评审记录。

最终验收：用户已明确通过黄昏、夜晚的天空、暗角与地形材质同步方案，两者均无局部低雾。三时段视觉适配验收完成，白天保留已通过的 C+ 静态烘焙低雾。

## 1. 目标与当前结论

专项从天空脏灰、远山与天空叠加发闷、主丘陵被带灰、铁路中景归属模糊，以及坡脚/谷地接壤生硬等问题开始。目标是在现有风格化场景中建立远、中、近层次与连续地貌，而不是改造为真实风景。

当前三时段默认均使用 `accepted-landscape`，保留原有地形几何、镜头与视差：

| 内容 | 白天 | 黄昏、夜晚 |
| --- | --- | --- |
| 天空渐变与全屏暗角 | 清透天空，暗角关闭；基础干净度通过，天空美感仍可深化 | 已分别适配天空，暗角关闭；用户已通过 |
| 主丘陵与地标 | 中景材质与空气关系已通过 | 同一空间关系，使用各自时段的空气色与衰减 |
| 坡脚接壤、谷地材质 | 包含左右及主丘前方；有雾谷地已通过 | 已复用材质分布，CPU/GPU 接壤取色同步 |
| 铁路中景 | 已接入默认；空气色 `#b9d2d8`，衰减 .115 | 已接入；黄昏 .12、夜晚 .10，保留原色、视差及空间发光 |
| 局部低雾 | 采用静态 C+ 完整体积光学烘焙缓存 | 不启用、不新增烘焙；普通空气透视保留 |

三时段视觉适配均已获用户认可。当前实现不等于已经完成统一地形、天气系统或天空美感设计。

## 2. S0–S4 交付

- **S0：诊断与边界。** 区分天空底色、全屏暗角、山体统一空气、局部雾和材质固有色。编号是视觉职责，不代表统一物理距离或 DOM 层级。
- **S1：清透天空。** 解耦显示天空与地形空气色，先解决基础干净度；关闭全屏暗角。黄昏与夜晚后来按用户要求直接适配，未重做整套基线诊断。
- **S2：丘陵及地标。** 恢复草甸固有色与受光体积，降低过强空气灰化；树木、农舍、风车随中景协调。
- **S2.1：接壤与低雾。** 保留接壤柔顺层。低雾从多轮失败试样最终转向程序化体积 C，再扩展成 C+；雾锚定丘陵脚下/低洼带，独立于麦田边缘，随同最近层投影。
- **S3：铁路。** 只调整铁路空气色和衰减，保留桥与列车材质、既有视差和空间发光。初期独立对照，随后按用户要求并入默认。
- **S4：谷地。** 确认大片灰绿色来自最近 WebGL 山层向前延伸的连续地表。原几何上增加虚拟前后深度与二维邻近控制，混合草甸、干草、偏冷草色。V1 变化过弱未通过；V2 增强分布后补齐主丘前方漏区，最终有雾版本通过。

主丘前方漏区的原因是早先中央保护权重贯穿整个纵列。最终保护范围依据既有坡脚曲线收回丘陵本体，前方谷地沿弯曲坡脚向前恢复材质，不新造横向色带或独立运动层。

## 3. 最终技术方案与保留实现

| 模块 | 职责 |
| --- | --- |
| `F3AtmosphereStudy.ts` | 三时段天空、丘陵、铁路参数；当前默认与保留对照；低雾仅白天开启 |
| `F2DistantHills.tsx` | 在冻结 F2 之上作宿主扩展，更新环境与投影，复用已有环境过渡与按需绘制 |
| `meadowFoothillMaterial.ts` | SVG 主丘陵受光与植被取色；`groundAt()` 匹配最近 WebGL 地表最终颜色 |
| `FoothillValleyMaterial.ts` | 同一网格上的谷地二维材质混合，CPU/GPU 使用相同空间公式与时段空气参数 |
| `HillFootFog.ts` / `ExpandedHillFogMaterial.ts` | 原始 C 与扩展 C+ 的程序化体积雾；保留实时调参和视觉对照 |
| `BakedHillFog.ts` | 对完整 RGB 光学结果与透明度高质量积分，缓存至 WebGLRenderTarget，交互重绘时合成 |

当前低雾缓存是每次页面生命周期内的 GPU 缓存，不是导出到磁盘的永久素材。相机平移/缩放复用纹理；重载页面或上下文恢复会重建。当前静态方案不做流动动画。

**技术边界：** 冻结 vendor 未修改；最近远山与其连续前延地表由 WebGL 承担，主丘陵仍是 SVG。两者通过投影和最终表面取色匹配实现连续。没有引入统一地形、独立谷地视差、额外地形网格或新依赖。

## 4. 试验结论与性能依据

单条 SVG 渐变/模糊带、多轮艺术贴图与密度贴图 D/E 在本场景未达到形体、内部结构及空间锚定要求，已舍弃；这不等于贴图技术普遍不可用。最终采用用户认可的 C+ 体积形态，再缓存完整体积光学结果，避免将密度切面当成成品雾。

保留的定向测量来自 Intel UHD 核显、1600×900 CSS、DPR 1.5，仅比较雾层：实时 C+ GPU 绘制中位数 **42.178ms**，烘焙合成 **1.008ms**，约差 41.84 倍；显式重烘焙的一次 GPU 样本为 **352.777ms**。缓存 2160×280 RGBA16F 纹理本体约 **4.61MiB**。这些数值不能推导整页 FPS 或其他设备表现。静止时两者都停止持续绘制。

详见 [保留的原始性能记录](../visual-system/f3-atmospheric-perspective-2026-11-20/fog-comparison/performance/README.md)。本次清理没有重新启动性能采样。
