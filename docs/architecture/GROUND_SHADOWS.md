# 场景阴影的用途与复用

2026-10-19 起，小范围试点使用 `src/world/render/GroundShadow.tsx`。沿用现有 SVG 局部坐标、资产配色和父级变换，提取人物／蒲团中已有的“环境渐变与接触分离”思路。

## 三种基础表达与独立实体投影

以接触关系、接收面和光照为先，再用材质调节边缘。材质不与软硬一一对应：同一张木桌可以同时有清晰的脚部接触影和柔和的桌下遮蔽；人物或软垫贴地处也可以有很窄的清晰接触边。

“环境遮蔽影／宽软影”用于本项目的简化美术表达。漫反射描述表面反射光的行为，不直接决定影子的软硬；树冠的有向落影也不能全部归入无方向的环境遮蔽。

| 类型 | 使用场景 | 实现 |
|---|---|---|
| 清晰接触影 | 支脚、底座与承托面紧贴处，木／金属／石制脚座通常适用 | `ContactGroundShadow`：小实色椭圆，紧贴触点，不附加模糊和偏移 |
| 柔和接触影 | 枕垫、拖鞋、织物与承托面的连续接触 | `SoftContactShadow`：较集中的核心与淡出边缘；材质只作参考 |
| 环境遮蔽影 | 物体下方更宽的光线遮蔽 | `AmbientGroundShadow`：独立椭圆渐变，外缘透明 |
| 实体投影 | 舷窗、装饰件等实体在另一表面上的落影 | 继续使用适合该实体的 feDropShadow；暂沿用已有定义，后续按接收面和边界逐项核对 |

前三种是独立的阴影几何，置于实体之前绘制。实体投影需要保留物体图形，并按轮廓和接收面生成落影，不能直接改成模糊原图。未创建无人使用的实体投影封装，也没有替换全局 softShadow。

## 接口

三个椭圆组件都接收数值型 `cx`、`cy`、`rx`、`ry`、`opacity` 和字符串 `color`。半径使用资产局部接收面单位；接触点的位置由各资产脚底几何决定，不使用统一的屏幕偏移。颜色和浓度留在资产端，以保持原有材质关系。名称沿用 GroundShadow，但也能用于局部坐标中明确的桌面、席面等承托面。

```tsx
<AmbientGroundShadow cx={0} cy={11.5} rx={10} ry={4.5}
  color="#1b120c" opacity={0.32} />
<ContactGroundShadow cx={-5.5} cy={10.5} rx={1.2} ry={0.45}
  color="#1b120c" opacity={0.26} />
```

环境渐变的中心强度为 1，60% 半径处为 .45，边缘为 0；柔和接触渐变的中心强度为 1，55% 半径处为 .85，边缘为 0。整体浓度由 opacity 控制。渐变末端在椭圆内收至透明，既不生成外扩滤镜尾部，也不依赖滤镜包围盒裁切。实际点击区域和屏幕阅读器中均排除这类装饰阴影。

`SoftSurfaceShadow` 用于非椭圆的独立阴影形状。显式提供局部几何 `bounds`、模糊标准差 `blur` 和可选用途 `role="ambient" | "soft-contact"`，把原 polygon／rect 放入其内部。滤镜使用 userSpaceOnUse，四边余量为 `ceil(3 × blur) + 1`；只羽化阴影形状，不把实体本体作为 children。书桌／电脑、地毯、折毯和烟管墙影的形状各自保留。

每个环境影使用 React useId 创建独立渐变 ID。资产详情预览继续由 usePreviewSvgIds 管理其内部 ID 与 url 引用；不要引入固定的共享渐变 ID。

## 首批应用与当时的迁移边界

- 龟背竹：原底影中心、半径、色相和最大浓度保留；改用渐变外缘，并在四根既有花架脚的末端补接触暗点。
- 茶桌：四处脚影使用 ContactGroundShadow，原中心、半径、颜色和浓度保留。茶桌整体的两块大环境影在本批保持原实现，避免将局部脚影试点扩成整桌重做。
- 已验收电波站、已定稿人物、蒲团、其它家具、实体轮廓和建筑布局均不迁移。

后续迁移先判断用途，再选组件。非椭圆的环境影应保留自身几何并单独核对羽化方式；需要滤镜时，按模糊标准差、偏移和目标几何留足输出范围，不能只扩大所有滤镜区域。每一批复核全景、放大、窄屏和原交互。
