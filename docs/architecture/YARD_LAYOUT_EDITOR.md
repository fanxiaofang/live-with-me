# 庭院布置

首页左下角「布置庭院」进入，面板可收起。主木屋锁定，其他建筑、南瓜架、蜂箱、羊圈、桂花树、两段前景木栅栏和五只散养羊可移动。圈内动物跟随羊圈。栅栏朝向只旋转地面坐标，立柱保持竖直。

野餐垫与野餐篮也作为整组物件接入，默认在主屋前方、桂花树右侧。`CountryPicnic` 通过 SVG `use` 直接复用 `WorldDefs` 中的 `asset-country-picnic-scene`，保持原有格纹、茶具、食物、草帽和接地阴影；保留的苹果树素材未接入。野餐组沿用环境色调滤镜及庭院保存／撤销逻辑。

「开垦土地」默认在南瓜架前方，使用 `TilledGardenPlot` 绘制贴地翻土面、浅垄沟、少量土块与断续草缘，按日暮夜调整土色。它独立拖动、撤销和保存，旧布局自动补齐；标记为 `ground` 的对象始终排在实体下方，浏览时不拦截点击。

选中土地后可分别调整长度、宽度（原尺寸的 50%–250%）和旋转（−180°–180°）。长宽沿土地自身两条边调整，旋转发生在地面投影前，草根和土块保持竖直；位置以中心为锚点。尺寸以可选的 `length`、`width` 百分数字段存储在物件布局中，旧存档默认 100%，沿用保存、撤销与还原逻辑。

20 组成片草簇／花草群落也可独立拖动：6 组前景草丛、10 组外围花草、2 组大片草花，以及从林间小木屋前、胶囊仓后拆出的 2 组草簇。在选择列表的「草簇与花草群落」中选择，或直接拖动场景。每组内部的草、花、穗子保留原有关系；建筑旁的群落保留所属建筑锚点，可另外调整相对偏移。原布局自动补齐新增草簇，无需重置。后拆出的木屋前／胶囊仓后草簇在升级时承接当前建筑偏移，之后完全独立，不再跟随建筑移动。正常浏览时草簇不拦截点击；配色仍遵循日暮夜主题。

- 拖动物件调整位置；拖动空地或滚轮控制视野。
- 方向键移动 2 个场景单位，Shift + 方向键移动 10 个单位；也可用面板中的微调按钮。
- Esc 在拖动中取消本次移动，其他时候退出布置。
- Ctrl/Cmd + Z 撤销；Ctrl/Cmd + Shift + Z 或 Ctrl/Cmd + Y 重做。
- 松手自动保存到当前浏览器的 `live_with_me_yard_layout_v1`。页面刷新后生效；不会同步至其他设备。
- 导出 JSON 包含相对原始布局的物件偏移，以及解析后的建筑 `sceneLayout`。可用于后续确定项目默认布局。恢复默认前需确认，恢复后也可撤销。

## 实现

`src/features/yard-editor/yardLayout.ts` 定义对象、可编辑范围、校验、建筑布局及镜头边界。存储字段为 `{version:1, objects:{[id]:{dx,dy,angle}}}`，相对默认位置，建筑比例保持现有值。

`YardWorld` 将完整对象通过 React portal 放到同一个 SVG 层，以接地点的 y 坐标排序。对象仍由原组件管理状态和交互，排序不重挂载。拖动期间固定排序，松手后更新前后关系。`YardObject` 的 `positioned` 标记表示建筑已经由 `SceneEntity` 应用偏移，避免重复平移；其他对象保留原始内部定位。地面附属物由 `YardAttachment` 或现有建筑锚点跟随。

拖动使用场景层 `getScreenCTM().inverse()` 换算屏幕坐标，以 SVG 根节点捕获指针，支持鼠标和触屏。拖动、指针取消、Esc、失焦分别提交或回滚一次事务；历史最多保存 50 次操作。编辑期间固定镜头所用的布局边界，避免建筑移动导致镜头跟随跳动；退出后导航和探索边界使用新布局。

中远景不属于布置对象。通行线只在编辑模式下显示，用于参考，不生成正式道路，也不执行碰撞避让。

## 定向验证

- `tests/unit/yardLayout.test.ts`：存储数据校验、中心锁定、建筑镜头锚点、栅栏投影及探索边界。
- `tests/e2e/yard-editor.spec.ts`：各类物件独立移动、不同倍率拖动、取消、历史、导出、刷新恢复及导航。
