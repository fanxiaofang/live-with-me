## 1. 使用方式与保护条件

- 用户明确不会使用 Boxy SVG。用户通过参考图、文字和画面反馈表达需求，Codex 负责几何、SVG 与参数修改；工具不能要求用户先学习矢量绘图。
- 靠窗桌、吧台和手边桌支持自由、不对称轮廓；不能只提供方形/圆形模板来代替造型设计。
- 保留已认可人物头部、四款发型、圆手、长袍身份和软影；原书架整体保留，既有交互和用户布局不因工具预览变化。
- 制作与运行时分开。几何与接触数据可在制作阶段计算，主场景只消费必要输出；关闭工具后不持续挂载辅助线、全方向预览或建模循环。

## 2. 现有基础

已有布局校准器可选择、拖动、微调物件并导出坐标；`SvgDetailView` 提供局部缩放，工位查看共享真实桌椅装配，独立人物工具已有四视图导出。`chairGeometry.ts`、`DeskSeatedCharacter.tsx` 已有桌高/坐高、落座锚点和键盘可达性。

首版在这些入口上验证，不先重建通用绘图软件。工具候选及投影限制见 [总入口的既有调查](PRE_PHASE_3_ASSET_READINESS.md#33-工具与当前投影)。Anatomy/Zdog 仍为候选，没有因本计划而安装；外部工具的默认相机不能直接套用主屋地面轴。

## 3. 第一版最小范围

| 能力 | 具体用途 |
| --- | --- |
| 资产结构预览 | 接入手绘/代码生成的任意轮廓，调桌高、厚度及支撑位置；不先实现完整曲线编辑器 |
| 接触点与区域 | 显示桌面、坐面、地面、键盘及可放物区域；拖动有限锚点并给出可达性提示 |
| 遮挡检查 | 单独查看家具后部、人物远近侧、桌沿/靠背等前部与接触影；整体排序和组内分层分别处理 |
| 三种尺度 | 单体、桌椅人物组合、实际房间预览使用共享几何；全景、近景、窄屏分别核对 |
| 草稿与输出 | 撤销、恢复、对照、导出参数与选定 SVG/JSX；正式应用与预览分开，保留旧保存格式的适配 |

不把增加工具当成全自动人体生成。锚点定位接触，姿态模板仍需造型设计和视觉评审；调正确位置不能替代长袍转折、肩背和袖子的形体。

## 4. 按使用位置校准

| 位置 | 主要关系 |
| --- | --- |
| 桌前坐姿 | 臀部/坐面、肩腕/键盘、长袍/地面、身体/椅背；超出可达范围采用合适收手状态 |
| 临时站台 | 地面接触、站距、台高、手与电脑/书；无椅，不当作固定坐姿工位 |
| 茶席 | 袍摆中心/蒲团、手/杯子、桌沿遮挡；朝向与不对称发型身份同时核对 |
| 卧榻与床 | 头/枕头、躯干承托、被沿和袍身覆盖；睡眠舱与木屋使用各自局部关系 |
| 懒人沙发 | 保留认可身体，检查书、手和新增手边桌，不默认重画人物 |

后续位置在首个试点有效后逐项扩展；不一次承诺完整八方向、骨骼系统或所有姿态自动适配。镜头平移/缩放也不会生成新的观察方向。

## 6. 2026-10-16 首版实施与单桌草样

### 入口与使用

独立生产预览为 `http://127.0.0.1:4178/`，左侧“检视工位椅子 (空椅 / 组合态)” → “接触校准 · 草稿”。既有空椅/坐姿、当前桌椅和双人示意入口保留；没有新增常驻全场工具面板。

- 桌面高度 20～27、厚度 1.2～3.6、宽度比例 0.85～1.15 可调；首版坐高固定为现有 14.2，不为调参重画认可人物。桌高同步带动桌上物件及键盘目标，桌板下沿到坐面不足 5.5 时提示检查膝部空间，不把提示当成真实碰撞检测。
- 桌面、桌脚地面参考、坐面、键盘及肩腕可达线可开关。椅子/键盘锚点可拖动，也可输入 X/Y；两个旧席位可分别选择，不增加或重新分配实际席位。
- 单桌和桌椅组合共用几何；按需显示当前装扮或明确说明的参考人物、隐藏人物检查空椅关系。原稿对照使用原 `DeskFrame`，草稿使用低细节结构，二者不混写。
- 撤销保留最近 40 步，试放返回后继续保留；恢复初始草稿读取进入工具时的实际布局，不重置用户布局。首版没有重做/多分支历史。
- 导出 `live-with-me/desk-study/v1` JSON 和当前视图 SVG，均标记为未确认草稿。JSON 含桌面参数及桌组/灯/杯/两椅/电脑的实际草稿坐标；SVG 去掉辅助线和锚点，保留独立 ID/滤镜引用。尚无自动导入/正式应用按钮，由 Codex 根据反馈继续制作。

### 异形桌与实际场景试放

接入一张浅凹前沿、右端略宽的异形靠窗桌曲线草样。几何使用原桌局部地面轴、当前投影和原脚落点体系；首版通过宽度联动支撑，不提供独立腿脚拖动。保留暖木色、脚套、接触软影及已有桌上物件，尚未补精细木纹、接缝或新布局。两处电脑和两椅沿用原状态，**不将本草样视为解决了双席局促**。

“放回房间试看”把同一草稿临时提供给真实场景，使用真实同住人和既有占用；不把参考人物分配到世界。试放条可返回工具或结束并恢复；期间隐藏正式布局编辑器入口，避免混用草稿与保存布局。关闭工具、结束试放后恢复原资产，辅助线卸载；不写 localStorage、容量或 v6 格式。全景和房间导航仍可使用。

主要源文件：`deskStudyModel.ts`（轮廓/参数）、`DeskStudyFrame.tsx`（草样结构）、`DeskContactGuides.tsx`（辅助线）、`DeskCalibrationWorkbench.tsx`（工具）、`DeskStudyContext.ts`（临时覆盖）；接入既有 `App.tsx`、`ChairInspectionModal`、`AtticDesk`、`DeskWorkstations`。制作数据与运行状态分开，没有引入新的运行时库。

### 本轮技术检查与证据

- `npm run lint` 和独立生产构建 `npm run build -- --outDir build/desk-calibration` 通过；主包既有 >500kB 提示保留，不据包体积作帧率结论。
- `tests/e2e/desk-calibration.spec.ts` 在 1200px / 390px 生产预览验证：拖锚点、坐标输入、超出可达范围收手、撤销、桌高同步、原稿对照、恢复、JSON/SVG 导出、试放/返回/结束、关闭后卸载辅助节点、真实身份不变及自定义 v6 保存内容逐字不变。导出 SVG 的 XML、重复 ID 和引用完整性检查通过。
- 同批回归既有桌面/390px 桌椅检视和无人席位三项；合计五项定向浏览器检查分组通过。最终补充试放与正式编辑器隔离后复验两项工作台检查，不将重复或历史通过累计成新覆盖。
- `node --import tsx --test tests/unit/desk-pose.test.ts` 单项通过。首次普通沙箱运行因 spawn EPERM 未启动测试，获子进程执行权限后通过，不记录为未解决产品故障。
