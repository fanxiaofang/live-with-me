# 人物比例稿与长袍站立四视图

本文件记录第一轮 v1。当前 v5 保留原刘海和正背面身体，在已修正的侧身结构上轻补厚，并增加接触阴影及木地板 / 草地材质对照。当前资产及对照图以 [v5 修正记录](CHARACTER_PROPORTION_REVISION.md) 为准，下文保留第一轮事实。

日期：2026-10-13（Asia/Shanghai）。状态：**站姿比例稿与导出功能已实现并验证，造型待用户评估；第三阶段未启动。**

用户指出，继续制作各个家具姿态之前，需要先明确人物本身的比例。现有 `public/character-shorthair-4views.svg` 和 front / left / back / right 四个独立文件确为坐姿：短发、毛线帽、圆润短躯干及折叠的袍身底座。观测站已有 `observatory_standing`，但露出腿脚，而且不构成完整的站姿四视图基准。

本轮按用户提供的长袍遮脚参考，补上中性站姿：原有短发与毛线帽、自然落肩、垂落双袖与袖口旁的手、连续长袍、少量下摆衣褶。参考图用于体型与衣服的垂坠关系；项目自己的头部和色板保持一致。

## 1. 比例与锚点

本稿约 3.2 头身，计算口径为**含毛线帽和毛球的站姿总高 / 名义头圆直径**，不能将帽子高度再次算入分母。现有 `CharacterHead` 的少量手绘曲线偏差继续保留。

| 测量 | SVG 局部单位 | 用途 |
| --- | --- | --- |
| 名义头圆半径 / 直径 | 7 / 14 | 四个方向及未来姿态的头部大小参照 |
| 头圆中心 | (0, −34) | 站姿头部锚点 |
| 肩线 / 正面肩宽 | y≈−29 / 约 12 | 头与躯干自然衔接，肩部轻微收在下颌后方 |
| 袖口 | y≈−9 | 双手自然垂落，袖口旁露少量手掌 |
| 下摆 / 正面袍摆宽 | y≈0 / 18 | 连续袍身覆盖腿脚；侧面按轮廓收窄 |
| 落地锚点 | (0, 0) | 日后人物移动、碰撞和场景接地参照 |
| 含帽与毛球的总高 | 约 45 | 约 3.2 个名义头圆直径 |

四个方向同倍率展示；基准线为头圆底、肩线和地面。侧面保留近/远袖的层级；正面与背面有各自的领口/背缝。左右侧面共享相同体型并镜像方向，当前没有持物或不对称服饰，不将镜像当成未来全部动作的处理方案。

SE / SW / NW / NE 沿用项目原有方向标签。旧坐姿总表的“2:1 Isometric Ratio”文本不用于推导本稿或场景地面投影。本轮没有修改旧图，以保持原稿；新图明确区分朝向与地面投影。

## 2. 单一绘制来源与导出入口

- `src/components/characters/StandingCharacter.tsx`：站姿身体几何，复用现有 `CharacterHead`，支持已有的帽子、发型、肤色、毛球及衣服颜色属性。
- `src/components/characters/characterProportions.ts`：本稿固定测量与参考色板，不是动态调整比例的产品控制面板。
- `scripts/generate-standing-character.tsx`：通过 React 静态 SVG 序列化生成总表及独立朝向，按文件/朝向给内部 ID 加前缀；总表与独立图共享绘制源，不手工维护五份身体路径。
- `public/character-shorthair-standing-4views.svg`，及 `character-shorthair-standing-{front,left,back,right}.svg`：生成的五个静态资产，总表为 1200×780，独立图统一 viewBox 为 `−20 −50 40 56`，背景透明。

重新生成：

```powershell
node --import tsx scripts/generate-standing-character.tsx
```

现有“导出 短发 4 视图 SVG”入口中增加“坐姿四视图 / 站姿四视图”选择；默认仍显示原坐姿。切换后总表、预览、四个单图、下载与复制使用同一姿态的文件。保留原坐姿五个文件及内容，新增导出窗口 Escape 关闭与焦点返回。

## 3. 与当前姿态工作的关系

合理顺序调整为：**人物身份与比例稿 → 各姿态的身体形变 → 家具接触与遮挡 → 动作循环**。站姿把身高、肩宽、手臂长度和袍身比例显露出来；坐姿通过弯曲、衣褶和遮挡压缩身体，不能把坐姿底部椭圆拉长就认定为站立。

本稿提供可评估的具体基准，尚不等于用户已经确认此比例。已有 [书桌椅首批样例](DESK_CHAIR_STATIC_REFINEMENT.md) 继续作为接触关系试点；后续姿态统一时应按确认的头部大小、肩宽和衣服体积再次校准，不把当前各组件的不同数字直接视为统一完成。

本轮站姿没有挂载到世界场景、替换观测站、改变席位分配或添加动画；静态文件在导出/预览时读取。没有引入新依赖，不新增每帧几何计算。此次未重复全景性能采样，也不作性能改善结论；先前长帧调查仍需继续。
