# 半开放生态屋顶：观看、镜头与遮雨方案

更新：2026-10-15（Asia/Shanghai）。

状态：**需求与候选方案已记录；生态屋顶、观看切换和遮雨适配均未实施、未技术验证、未用户最终验收。** 优先顺序见 [第三阶段前总入口](PRE_PHASE_3_ASSET_READINESS.md#6-当前优先顺序与历史顺序)。本专项可单独推进，不代表启动全部天气阶段。

## 1. 用户需求与参考边界

[归档的用户风格参考图](references/eco-roof-style-reference-2026-10-15.png) 只用于屋顶的风格和样式：有厚度的木框、外露梁架、玻璃屋面、斜坡上的苔草和疏密不同的植物。

- 小屋保持单层，不照图增加二楼、楼板、楼梯或居住空间。
- 屋顶可独立悬浮，不要求与现有墙顶/梁柱真实支撑连接。
- 设计优先服务观看：保留人物、完整书架、桌面、茶席和活动区域的可读性。
- 已有房间、建筑摆放、人物造型及镜头机制继续保留；不因参考图改变成一座更大的建筑。

候选形态为后侧和两翼有植物的木框生态屋面，局部嵌玻璃，朝观看者采用剖切表达。木框厚度、悬浮高度、坡度、植物密度及剖面范围均待样例评审，不是已定稿参数。

## 2. 三种范围分别定义

| 范围 | 职责 |
| --- | --- |
| 可见屋顶 | 当前画面画哪些屋面、木框、玻璃和植物 |
| 遮雨覆盖 | 哪些室内区域逻辑上受保护；不随为观看而省略的屋面一起失效 |
| 观看与交互 | 室内镜头仍围绕人物/家具；屋顶装饰不截获物件点击、拖动、触摸或焦点 |

剖面省略和透明玻璃不等于实际露天开口。若以后明确设计真实天窗开口，应另外确定玻璃或接雨表达，不能混用逻辑。

## 3. 当前镜头与候选观看状态

当前镜头只有平移、缩放及房间聚焦，没有绕屋旋转。屋顶依附主屋的实体局部坐标与主舞台变换，悬浮由相对高度表达，不另设背景视差。

- 全景：比较保留较完整的生态屋顶轮廓，表达有覆盖的小屋。
- 室内近景：比较省略/收起近侧遮挡屋面，保留后侧或边缘提示；切换方式尚待验证。
- 布局编辑：应能临时隐藏屋顶查看接触点和通道，关闭预览不修改实际布局。

室内 focus 不直接以整片屋顶包围盒重新自动缩放。分别检查 `roomTargets.ts` 的活动区/上下文、`explorationBounds.ts` 的建筑外包络和窄屏 slice 裁切；不得为看屋顶随意拉远默认室内镜头或改变第二阶段阻尼。

状态切换优先使用明确的观看状态；若需要缩放阈值，应有稳定过渡和滞回，避免连续操作时闪跳。首样先做静态形态，不默认新增每帧遮挡计算或成片植物动画。

## 4. 雨层必须配套处理

当前 `AtmosphereOverlay.tsx` 的雨是 `absolute inset-0`、`z-10` 的整屏层；单独添加 SVG 屋顶不会自动挡住它。

候选处理为区分建筑后方雨与必要前景雨，并用明确的室内遮雨区域排除穿雨。优先验证共享世界变换的几何裁切；如保留屏幕空间叠层，必须精确匹配相机、视口及过渡。具体裁切实现需比较性能后选择，不预设必须用大范围模糊遮罩。

房间切换期间约 400ms 的相机过渡也要同步，不能只在结束时更新遮雨范围。雨丝、玻璃、屋面及剖面状态分别核对；屋檐滴水等后续细节可独立延后。

本专项解决主屋屋顶相关的观看和遮雨；五主题天空、彩虹、极光与完整大气工作继续由 [第三阶段规划](PHASE_3_WEATHER_ATMOSPHERE_PLAN.md) 维护。

## 5. 样例、检查与成本

1. 先用薄层屋面、少量木框和成片植物轮廓验证体量及剖面，避免为未通过的构图增加大量细节。
2. 检查全景、各主屋房间、连续拖动/缩放/切换、桌面和窄屏；人物、原书架、挂画及新桌保持可见可操作。
3. 分别核对屋顶显示/省略、雨天遮蔽、运动期间错位和刷新后的状态；独立预览使用隔离的 SVG 资源 ID。
4. 与 [性能诊断记录](SCENE_PERFORMANCE_DIAGNOSIS.md) 同条件比较简单屋面、植物细节和雨层裁切的成本，包括高 DPR 和内存/滤镜面积。
5. 静态形态、技术关系、性能结果与用户视觉评审分别记录。完整屋顶或工具完工不自动成为第三阶段全部工作的硬性门槛。
