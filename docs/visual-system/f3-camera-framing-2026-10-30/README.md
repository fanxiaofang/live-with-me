# F3 相机构图调整（待视觉审阅）

基线：`origin/main` 的 `9b4bad5`，分支：`f3`。日期：2026-10-30。

## 范围

用户要求中景、远景任何内容都不能改动。本轮最终实现仅涉及相机取景、相机边界，以及手机初始收起同住人面板。草地实体尺寸、草地边缘、建筑摆放、丘陵、树木、风车、农舍、麦田、铁路、天空、材质、F2 标定与各景层视差参数均保持 main 原样。开发期间试过的丘陵位移已全部撤回，不属于最终方案。

`cameraMath.ts` 中 `{ x: 0, y: 135, zoom: .66 }` 继续作为原有景观的标定参考。新增 `overviewFraming.ts` 单独计算用户打开项目时的实际取景，避免调整默认镜头时连带移动所有背景标定。

## 行为

- 默认总览最大缩放由 .66 改为 .54；根据真实 SVG 可见裁切范围适配手机和超宽屏，完整容纳屋顶、烟囱及地面主体。
- 手机优先居中整栋主屋，仍可手动拖动到两侧设施；初始收起同住人面板，可点击展开。
- 总览按场景实体边界安排下缘；缩到最远 .45 时，实体下缘与画面底部保留约 6% 的间距，向上拖动时最多约 16%，避免出现过多空草地。
- 滚轮和缩放按钮在总览尺度下保留下缘构图及访客已有的平移偏移；房间取景、手指中点缩放及编辑器继续使用原有投影。
- 回到总览、重新选中房间和窗口改变尺寸后，按当前可见画幅重新取景。最近缩放仍为 2.5。

桌面 1600×900 默认相机约为 `(0, 153.4812, .54)`；390×844 手机约为 `(31.1908, 215.6889, .519846)`；2560×1080 约为 `(0, 98.8482, .487774)`。最终视觉效果待用户审阅。

## 验证与限制

类型检查、69 项单元测试、生产构建通过。新增 5 项浏览器检查通过，覆盖桌面/手机/超宽屏完整木屋及原位风车可见、最远镜头下缘、最大缩放、复位、窗口缩放和减少动态效果。

相关专项回归配置为 `playwright.camera.config.ts`，可运行：

```powershell
npx playwright test --config playwright.camera.config.ts --reporter=line
```

已有房间切换断言同步到 main 已合入的屋顶上下文取景；F2 地标检查更新为当前 31 棵树、两处农舍和一座风车，共 34 个根点。触摸切换测试等待浏览器帧后再读取镜头，避免把尚未完成的上一步触摸混入位移差值。

广域探索额外运行了 legacy 对照场景。其快速反向缩放接缝检查出现一次约 30.74 单位的采样空隙；独立读取同一路径的实际矩阵及边界未复现（采样均有覆盖），仍记录为待核对项，不宣称全套浏览器回归通过，也没有借此修改中远景。首轮开发服务器的热更新曾干扰部分浏览器检查；最终复跑切换到 3014 端口、关闭 HMR 的独立服务。

本轮没有进行真实手机硬件、Safari 或 Firefox 验收。
## 最终复跑补充

当前场景的专项配置包含 40 项检查：其中 39 项在分组运行及复跑中通过；快速房间切换单独运行曾通过，但最终长批次中再次出现 5 秒动画等待超时，仍列为不稳定项，不宣称 40 项全部稳定通过。受热更新影响的工位拖动与触摸交接复跑通过。桌面及手机 F2 实际投影检查也已通过，未修改其实现。

扩展到历史景观检查时，除前述 legacy 动画接缝项外，包含完整昼暮夜切换和截图的重型 F2 测试在 90 秒总时限内未完成（此前相机运动与根点投影断言通过），也不计为全项通过。
