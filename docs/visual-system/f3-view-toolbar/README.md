# F3 右侧视角工具栏与阁楼取景

## 最终入口评估

| 入口 | 处理 | 原因 |
| --- | --- | --- |
| 整栋小屋 | 主要入口 | 默认取景和回到整个庭院的共同起点 |
| 阁楼 | 主要入口，新增独立镜头 | 原“我的阁楼房间”其实指向一楼工位；现在对准真正的上层平台及连接楼梯，也可点击平台或用键盘进入 |
| 公共起居角 | 主要入口，放大 | 桌面从约 1.1472 提高至 1.45，约增加 26%；取景集中在茶几、壁炉与阅读沙发，窄屏仍按画幅适配 |
| 工作区 | 更多去处 | 保留一楼双人工位的访问能力，去掉错误的阁楼命名 |
| 旧胶囊仓 | 更多去处 | 独立休息设施和对应在场状态，保留访问 |
| 林间小木屋 | 更多去处 | 另一处独立卧房，具有不同场景形态与床位，保留但不占主要入口 |
| 电波观测台 | 更多去处，缩短名称 | 独立设备与信号交互；名称与庭院右侧实际位置一致 |
| 林木的书房 | 删除独立工具栏入口及旧名称 | 阅读沙发属于公共起居角，复用同一取景；原在场与沙发座位数据继续有效 |
| 前廊 | 删除工具栏入口 | 与顶部信箱按钮、场景中的实体信箱重复；仍可从信箱直接操作 |

## 行为与边界

- 工具栏从底部改为右侧居中，桌面默认展开，手机默认收起。选中手机视角后自动收起，再次点击指南针按钮可展开。
- 折叠按钮提供 `aria-expanded` 与 `aria-controls`，Escape 可收起并把键盘焦点移回按钮。隐藏内容不能继续接收 Tab 焦点。
- 三个主要入口直接显示，其他四个放入原生 details 的“更多去处”；短屏展开后内部滚动，面板不超出可见画面。
- 折叠容器 46px 包含两侧边框，实际按钮至少 44×44px。
- 相机视角新增独立的 `WorldViewId`，阁楼不冒充一楼人物的房间；旧保存的 `my_room` 与 `friend_room` 在场/座位数据不迁移、不丢失。
- 原 `friend_room` 相机解析到公共起居角，工具栏也标记公共起居角为当前视角。
- 中远景、F2 渲染、视差参数、地形与设施坐标保持原样。

## 验证

- 类型检查通过。
- 70 项单元测试通过，包含阁楼与起居角的桌面、手机和超宽屏取景边界，以及旧阅读沙发 ID 的镜头兼容。
- 本轮 5 项新浏览器专项分组通过：主要/次级入口及移除项、折叠和键盘、真实上层平台、起居角放大、手机点击区与自动收起、短屏滚动。
- 生产构建通过；原有主包体积提示仍存在。
- 本轮旧房间导航广域回归的初次运行包含动画等待超时和调整前的阁楼边界失败，未宣称整套历史回归通过。阁楼边界已通过本轮新专项验证，上一轮 legacy 接缝与重型环境切换的记录仍保留在相机构图说明中。

本轮专项可通过 `npx playwright test --config playwright.camera.config.ts view-toolbar.spec.ts` 重跑。视觉效果待用户审阅。
