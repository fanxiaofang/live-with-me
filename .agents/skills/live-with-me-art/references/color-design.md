# 配色：学习关系，而不是封闭色板

## 源码中可复核的关系

| 实例 | 观察 | 可迁移的原则 |
|---|---|---|
| 南瓜 | 暗橙底、橙色两侧、金黄中央瓣；绿色蒂叶与深木架 | 通过邻近色相与明度变化塑造圆润体积，鲜色集中在主物上 |
| 蜂箱 | 暖木正面 `#e2b477`、较暗侧面 `#b0834c`、深棕线 `#4a2e16`；绿色屋顶与小金色徽记 | 结构色组连续，另一色相用于部件区分，最高亮度只占小面积 |
| 拖拉机 | 红车身、亮红顶缘、暗红凹槽；近黑轮胎、黄轮毂 | 饱和主色完全可行，用深色结构稳定它；亮色配件有功能定位 |
| 咖啡柜 | 木色承托象牙白唱片机、黑胶盘、金蜜液与不同釉色小杯 | 邻物不必同色；通过大小、明暗和材质形成统一 |
| 炉子 | 多套色相方案共用 facet / stroke / hi / plinth 等角色 | 换色应替换一套材质关系，而非只替换主体 fill |
| 桂花树 | 叶团由 deep / shade / leaf / light / tip 构成，金色小花点缀 | 层级与光照组织颜色；不是每片叶子挑一个随机绿 |
| 海报画芯 | 夜海使用深蓝、冷蓝浪光；暖木框与浅卡纸负责连接室内 | 画中画可以有独立色域，不必把内容染成室内木色 |

上面的色值是观察证据，不是允许使用的颜色清单。既有资产已经同时包含鲜红、金黄、冷银、靛蓝、近黑、灰米色和多种绿；统一不依赖“全都暖色”或“全都低饱和”。

## 为全新颜色推导一套方案

1. **先定材质**：是有釉陶器、亚麻、油漆铁皮还是鲜果？同一个蓝色在布料上需要宽而弱的亮面，在釉面上可以有一条窄而亮的反光。
2. **看所在背景**：深柜格里的深色壶需要可读的口沿/受光面；亮草地上的浅物件需要较稳的底部与接触影。不要只在白底上选色。
3. **确定角色与面积**：先选主体色、结构/辅材色和小面积点缀。可从“大主体、中辅材、小点缀”起步，但不把 60/30/10 等比例当成验收公式。
4. **先排明度，再定鲜艳度**：分出亮面、主面、暗面、接缝/内腔，确保缩小后仍可辨。高光通常最亮，内腔最暗，但不是每个物件都要跨越纯白到纯黑。
5. **推导色相变化**：亮面可根据光源略偏暖，暗面保留材料色或略偏冷；不要机械地所有暗面加黑、所有亮面加白。木材的亮边偏木色，蓝布的阴影仍能读出蓝，紫釉可以有红紫主体与蓝紫暗部。
6. **控制彩度**：主物可鲜艳；辅材和背景给它留空间。最高彩度不必恰好等于最高明度。深色也可以有饱满色相，浅色也不必粉灰。
7. **做同场景判断**：把候选放到实际邻物旁，看第一眼是否抢走不该抢的注意力。如果抢眼，依次调整面积、亮度、高光强度、彩度，不直接给整组覆盖灰色滤镜。

可以借助 OKLCH/HSL 调整候选，但感知明度并不等于 HSL 的 L；最终按渲染结果判断，输出项目支持的颜色格式。无需为选色引入新运行时依赖。

## 新色示范：莓紫搪瓷水壶

以下为推导示范，未作为场景新资产验收；不是必须照抄的固定新色板。

| 角色 | 示例色 | 用途 |
|---|---|---|
| 主釉面 | `#9B3972` | 清楚的莓紫主体，区别于环境木色 |
| 受光面 | `#C76493` | 主体向暖玫红抬亮，仍保留釉色 |
| 暗侧面 | `#642C61` | 更深的偏冷紫，交代壶身转折 |
| 深结构线 | `#45203D` | 口沿、把手连接和遮挡边界 |
| 窄釉面高光 | `#F7DBE8` | 少量反光，不做一圈白边 |
| 辅材 | 暖木手柄、少量黄铜连接件 | 与现有生活器物建立材质联系 |

将这套颜色用于毛毯时不能原样复制高光与边线：布料需要更宽、更弱的亮面，折层阴影和柔和滚边代替釉面反射。

## 同场景比较：鲜艳度、明暗与色块面积

比较两件资产时，同时看饱和度、明暗跨度、鲜色占比与集中程度。南瓜架的橙金果实面积大、集中，深木与深土承托鲜色；菜园的大面积棕土、中绿叶与小而分散的果实，会让整体显得柔和。不能只据此把整片菜园提高饱和度或把南瓜统一压灰。

- 对齐颜色分工与光照关系，允许不同木材、物种及主次拥有自己的色域。浅木香草槽可用深土、端面、接缝和支点建立结构，不必改成南瓜架的深木色。
- 鲜果用有面积的主体色、柔和受光面和克制暗侧塑造饱满感。过多红褐暗部、陶土般主色或仅靠细亮条，可能让果实显干；增加亮面也不要覆盖到失去原主体色。
- 嫩绿集中于嫩叶或受光处，内层与成熟叶保留分量。不同物种可有不同绿色；具体色相服从当前设计和用户偏好，不强制所有包菜灰蓝绿或所有叶菜黄绿。
- 自然土面通常是承托背景，结构木料负责稳定，花果或嫩芽提供重点。先调整相应部件的色面和面积，再考虑整体鲜艳度；同一配方不能适用于所有部件。

以上是本项目南瓜架、菜园和苗圃比较所得的决策示例，不规定固定色值、受光面积或统一饱和度。

## 昼暮夜与整体协调

先追踪现有颜色链：有的资产在组件中按日暮夜选择材质色组，有的由所在图层统一应用 `field-environment-tone`。沿用该对象当前处理方式；不要在已经受环境处理的对象上再复制一套加暗／偏暖滤镜。环境照明、季节叶色与树种固有色是不同概念，用户未要求时不新增季节状态。

- 光照变化与固有色分开思考。遵循已有主题：`timberColor` 保留暖木色，桂花树对不同光照提供分层色组。
- 发光源附近可出现局部暖反射；不要给所有物件画同样强的橙色边。
- 夜间压低亮度仍需保留轮廓、材质和空间关系；避免所有深色变成同一团黑，灯具也不应整片过曝。
- 地面磨损从承接地面的土/草颜色推导，并随主题变化；它不属于需要高饱和突出的小道具。

## 常见失败

- 主体色名义上存在，但大面积浅层覆盖后只剩粉白感；应先减小覆盖面积与强度，再判断是否需要提高底色彩度。
- 暗部面积过大、叶冠变成一块深色底座，或所有叶团都有同样的浅色帽；先调整遮挡结构与受光面积，不靠整体提亮解决。
- 只在白底或放大近景判断；应在相邻木材、草地、麦田中检查明暗分离与注意力分配。没有适用于全部资产的固定亮暗面积比例。

- 只从旧文件复制几个 hex，却忽略它们分别用于何种材质、明暗和面积。
- 把暖色氛围解释为禁用蓝紫，或把允许鲜色解释为必须全物体高饱和。
- 所有阴影统一黑色、所有高光统一白色、所有轮廓统一深棕。
- 用海报内部的强烈叙事配色直接覆盖整栋建筑。
- 新色在局部白底好看，但融入原场景后与草地等明、与背板糊成一体或比主屋更抢眼。
