# 材质、线条与体积

## 线条的四种任务

| 类型 | 画法 | 作用 |
|---|---|---|
| 轮廓/遮挡边 | 材质深色、必要处明确；允许部分边界仅由色块表达 | 分离形体，避免全物黑边贴纸感 |
| 结构线 | 顺接缝、口沿、折面、扣件走向，通常更细或降低对比 | 解释如何组装、哪里有厚度 |
| 纹理线 | 稀疏、断续、有方向，弱于主要结构 | 提示木纹、织线、叶脉、草纤维 |
| 反光线 | 只放受光处，长度、宽度、冷暖随材质 | 区分釉、金属、玻璃和哑光材料 |

咖啡小物源码常见 `strokeWidth` 约 0.4–0.75，蜂箱约 0.5–0.8，地板接缝约 0.75 且带透明度。这些都是 **SVG 局部单位**，经过组件缩放和相机后才是屏幕宽度。不能据此规定所有资产统一“0.6px”。拖拉机胎纹等宽线本身还承担几何形状的任务。

对照相邻资产在同一屏幕尺度的线条重量。缩小时先删纹理、合并色块，再决定是否增粗轮廓；不要用统一粗描边拯救细节过多的问题。轮廓转角可用 round join；木板倒角高光在端点需要截齐时用 butt，避免圆头越出板面。

## 分材质画法

“分面”是光照与体积的组织，不意味着每种材料都要切成硬多边形。木板、石块和金属转角可清楚截齐；树冠、软布和有机形体用曲面、受压转折及遮挡分层。生硬折角不能代替手作感。

| 材质 / 参考 | 形体与配色 | 线条与细节 | 避免 |
|---|---|---|---|
| 木材：蜂箱、柜架、地板 | 明确顶面/正面/暗侧面，端面与承重厚度；暖棕内部有明暗与色温变化 | 顺木纹的少量断线、暗接缝、同材质浅金倒角；地板板间微色差 | 每块板一个木结、逐板白色亮边、密集条码纹 |
| 果蔬：南瓜及配件 | 重叠瓣块建立饱满体积，亮瓣与暗瓣有连续色相，蒂叶做小面积对照 | 茎线略弯，叶脉少而准，主体可无外轮廓线 | 所有瓜等大等距、全身描重黑线、塑料球状镜面 |
| 陶器：杯、花盆、茶壶 | 杯/盆口内外层，口沿厚度与内部深色；釉色可鲜明，素陶可安静 | 釉杯可用局部强反射；哑光盆用宽弱亮面与少量斑点 | 把每种陶器都画成玻璃、以大量颗粒代替形体 |
| 玻璃/液体：蜜罐、豆罐 | 内容物决定主色，瓶底厚度和液面椭圆清楚 | 少量明亮竖条、透明侧壁；标签与布盖各有材质 | 整瓶白雾、四边同亮、看不见内容物 |
| 金属：摩卡壶、炉子、拖拉机、小火车 | 摩卡壶冷银切面反差强；涂漆机械保留主色面；炉体暗面厚重，门腔更深 | 窄棱光、少量铆钉/黄铜件、深色连接结构 | 所有金属都镀铬、每条边都发光、无区别地抹灰 |
| 黑胶与复古设备 | 象牙白机壳、近黑唱片、少量鲜色按键构成主次 | 唱片浅椭圆与桌面一致；固定空间反光与旋转纹理分离 | 直接旋转屏幕椭圆造成轴向摇摆 |
| 布料/床品/软椅 | 厚折层、鼓起、受压凹陷；颜色可饱满，阴影仍保持布色 | 柔和滚边、有限缝线、少量织线与宽亮面；软接触影 | 陶瓷式白色亮条、随机毛边、织线密到闪烁 |
| 干草：羊圈草卷 | 顶椭圆、圆柱厚度、叠放遮挡；浅金顶、较深金黄侧面 | 少量卷芯环、捆绳与外逸短草 | 全体密密麻麻画草丝，堆叠没有接触 |
| 石材：羊圈墙、水槽 | 分出厚壁、端面、槽口内壁和水面；灰色带环境冷暖 | 少量拼缝、断角和明暗面 | 平面线框槽、每块石头完全同形 |
| 室内植物：龟背竹、书架小盆 | 成熟叶/新叶/背叶分色；盆土、盆口、脚架层次明确 | 代表性开裂孔洞、少量叶脉与气根 | 每片叶子同一椭圆、全体同亮、无土无承托 |
| 桂花树及其他树木 | 桂花可用不等大冠团互叠；其他树种先按生长结构确定剪影，见 [植物与树种](plants.md) | 枝条走向、受光肩面、稀疏叶片和聚散有别的花／果 | 所有树种复用桂花团冠；连续高光带、随机散点、整树等密度 |
| 地面使用痕迹 | 在真实使用点附近呈断续浅土色，留草间隙；形状沿承接地面展开 | 无硬描边，中心较实、边缘渐淡，少量草色短划融入 | 大块实心泥饼、道路一样连续、强阴影使痕迹浮起 |
| 开垦土面与土垄 | 棕土主体承接浅缓垄肩与断续沟槽，边界有草皮破口和局部松土 | 宽缓色面说明隆起，少量暗沟和碎土补充材质；接触处有选择地明确 | 等距长木板、重复竖划、整圈锯齿或描边；靠强阴影贴到草上 |
| SVG 插画/画框 | 画芯可平面化并有独立主题色；框体仍有厚度，卡纸、挂绳连接室内 | 按画芯叙事保留关键轮廓；实际缩小时仍有视觉中心 | 强迫画芯服从家具投影、缩小后密线成团 |

## 手作感和细节预算

先保留一种材质最有辨识度的两三类特征。例如咖啡袋的折边、标签与阀，草卷的顶面卷芯、捆绳与少数散草，杯子的厚口沿与浸釉边。数量是制作起点，不是必须凑满的公式。

轻微不对称要有成因：布的下垂、枝的生长、陶口的柔软曲线、木板拼缝的错落。支撑轴、投影方向、器具功能仍然可靠。不要把“手绘”解释成画不准结构。

大面保持安静，小物可以在视觉中心有较高反差；自然植物可不描整圈轮廓。实际缩小时应先读到整体，再读到部件，最后才是纹理。

## 阴影与发光

- 硬支点优先 `ContactGroundShadow`；较宽的环境衬影使用 `AmbientGroundShadow`。
- 枕头、布料等可用 `SoftContactShadow`；已有不规则软投影可用 `SoftSurfaceShadow`，只模糊影子并留足滤镜边界。
- 影色结合承接面，紧贴支点的阴影比宽环境影更紧、更实；不要用一个远离脚底的大椭圆假装接地。
- 灯光和炉火可柔化，但灯罩、框架、玻璃边沿仍清楚；白天辉光通常更弱。不要因灯光影响无限扩大此次修改范围。

## 地面朝向与草土交接

- 共用现有地面投影与坐标换算，区分地面上的朝向和物体立面。地面脚点先变换，再加竖直高度；茎、草叶、支架及土块隆起不能随地面被压扁。涉及摆放数值时按场景编辑技能处理。
- 纯平面纹样可复用地面变换；有体积的多朝向资产还要判断可见肩面、沟槽宽度、遮挡和固定光照。直接旋转整件绘图、重建一套屏幕横竖轴，或只换一个轮廓数组，都不保证视觉上处于同一地面。
- 土地应在空地状态也能读成贴地。接近矩形的投影不必然错误；若像竖板，先看纹理是否变成立面划痕、边界是否像板框、是否缺少地面交接，勿默认再压扁整块土地。
- 草土交接用少量有成因的草舌、残草、松土塌口和越界碎屑打断边界，保留若干清楚的开垦边段。遮挡草叶从外侧压住土边；不要用大量草簇遮盖结构问题。使用遮罩露出真实下层草地时，资源 ID 按实例隔离。
- 不用封闭深边、大椭圆投影或规则锯齿制造“贴地”。接触暗部集中在真正的支点、土块与局部沟槽，外围环境影较轻；具体强度按当前承接面判断。
