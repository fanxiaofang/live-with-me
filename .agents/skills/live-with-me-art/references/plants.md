# 植物结构与品种：共用美术关系，保留个性

用于树木、灌木、蔬菜、香草及成片植物。按当前对象阅读相关部分。颜色、光照、线条重量可以共通，剪影、分枝方式和叶片组织应由植物本身决定。

## 先定生长结构

先看根部、主干、主要分叉与外轮廓。选几条能解释冠形的枝条，再沿枝条组织疏密；不要先摆几个圆团，再用树干连接。叶隙与枝条露出的区域也应有方向。

| 类型 | 当前项目适合的轮廓与结构 | 需要避免 |
|---|---|---|
| 桂花守护树 | 老干分叉、宽展而错落的常绿叶团，可保留团簇概括；对生尖叶与叶腋金桂形成识别点 | 均匀云朵轮廓、每个叶团相同亮帽、每枝同样三朵花 |
| 白桦 | 挺拔、渐收的浅色主干；图形化不规则树皮斑块配横纹；次要分枝承接多层不规则叶簇，下部枝梢有叶簇覆盖 | 对称下垂的“八字刘海”；碎叶掩盖整体剪影；只有横纹或裸露无承接的枝梢 |
| 落叶松／当前针叶类 | 向上收尖的主轴，错层横伸、局部下垂的枝簇；明暗随枝层分开，少量针束提示方向 | 整齐重复三角片、圣诞树式等距裙边；以针叶线条填满每一层 |
| 暖色阔叶类 | 先给出有伸展方向的主分叉，再形成不对称展开的冠缘；穿插透光间隙和碎叶簇，主次侧枝有所区别 | 直接复用桂花团簇或三个球冠，只将叶色换暖；用花瓣状亮斑代替枝叶组织 |
| 低矮灌木 | 数处根点与枝梢汇成高低错落的低冠，外缘少量尖叶打破整齐边界，底部与草地穿插 | 同心色带、整齐绿馒头、环绕整丛的硬边／土台 |

这里是本项目的设计方向，不是所有品种都必须遵守的植物学模板。“暖色阔叶”是外观类别，`broadleaf` 也是实现枚举，不能据此认定是真正红杉；若目标确为红杉，要改用相应主轴和针叶枝层结构。用户未要求时不擅自更换物种、位置、比例或新增季节系统。

## 从枝叶组织出体积

- 后层叶与冠内凹处使用保留色相的深绿；主叶色负责大面积识别；亮叶只出现在有受光依据的肩部或少量嫩梢。
- 通过叶簇互相遮挡和有方向的空隙交代体积，不在每一团表面盖相同形状的浅色贴片。自然叶冠可有尖叶与局部折转，避免连续锯齿或生硬多边形整圈收边。
- 叶枝沿生长方向，叶片尺度随距离简化。花、果和嫩梢在少数位置成簇，留疏处和被遮住的部分；不将一套花叶组合均匀印满树冠。
- 主枝可以露出，隐入叶冠的端部应有连续遮挡。检查叶冠摆动或缩放后的交接，保留合理余量；不要把自然分叉全部遮成一团。

## 比较与参考边界

先关掉花朵和细叶，判断树种轮廓是否已有区别；再放回真实场景尺寸，确保差别不是只能在超大近景看到。远树不需要补齐这些微细节。

白桦早期“三团冠”、细碎叶与对称下垂版本已被否定；后续 `NearFieldTreeShape.tsx` 的 `BirchOpenCrown`／`open-weave` 在补齐下部枝簇后获用户通过，并复用到麦田边白桦。借鉴其挺拔主干、图形树皮和层叠叶簇；不把历史失败描述继续当作当前版本状态。落叶松／针叶枝层曾获正向反馈，暖阔叶不能因此被视为已通过；桂花的团簇概括仅适用于该树。后续修改仍以当前源码和最新明确反馈为准。

## 蔬菜与香草：先画生长结构

先确定根点、主茎／叶柄、主要分枝及花果连接，再组织叶量。识别一种作物不只靠颜色：

| 结构类型 | 场景尺寸下应保留的特征 | 常见误读 |
|---|---|---|
| 管叶：小葱 | 弯曲主体粗细相对均匀，末端收尖；窄侧暗面说明圆柱体，短白茎错落露出 | 中间宽、两头尖的扁带叶；一束细亮线；白套管底座 |
| 扁带叶：大蒜 | 从短假茎不同高度交错抽生，叶面可折弯、垂尖；根颈收进土里 | 同点放射的整齐 V 形；像龙舌兰的硬剑叶；切平的白块 |
| 包裹叶：包菜 | 外叶承托菜球，内叶不对称搭接、收拢，折边局部可见 | 同心色环、螺旋、按钮亮心 |
| 匙形叶：上海青、小白菜 | 厚叶柄托住圆润叶面，外叶与新叶在大小、角度和前后位置上不同 | 叶柄均匀放射；与叶冠脱开的浅色末端 |
| 复叶与裂叶：草莓、土豆、胡萝卜、香菜 | 保留有辨识度的组合：三出叶、开展的复叶枝、羽状叶束、分枝上的裂叶；叶间有空隙 | 整片扇面、沿茎堆叠的圆叶、尖叶冠，或为疏松而削成零散幼苗 |
| 结果／攀缘作物：番茄、辣椒、豆角、南瓜 | 主侧枝与支撑关系清楚，果梗、叶柄、藤节能追溯；果实有完整色面，部分露在叶冠外 | 红钩或绿线代替果实体积；藤从果实侧面凭空长出；架脚与根点悬空 |
| 香草：薄荷、柠檬香蜂草、迷迭香 | 对生叶与分枝、宽圆略鼓的叶面、沿主枝及短侧枝生长的针叶分别建立识别 | 同一叶片模型换绿；整齐装饰树；几根放射针线 |

这些是结构提示，不是统一的叶片数量、植物学精度或造型模板。叶量与密度结合成熟阶段和用途判断；保留主要生长关系后，可以适度夸张或可爱化。

## 比例、姿态与可爱造型

- 在实际场景中分别判断整株高度、冠幅、果实及支架。增高植株不能只扩大枝叶，导致果实相对消失；需要放大主果时单独调整，不把全株一起拉伸。鲜果可以适度夸张，叶菜也应有自己的体量。
- 先用轮廓和完整色面保证辨识，再决定叶脉、种子和锯齿是否值得保留。细线、碎尖角和小高光缩小时可能只留下硬、干、碎的感觉。
- 自然变体改变生长关系：主侧枝方向、外叶展开、叶片正侧面、果串位置与成熟状态。轻微缩放、镜像或整株旋转不能独自承担变化；变化后仍须连接可靠、光照稳定。数量、幅度和混入比例按当前画面决定，不固化本轮参数。
- 用户喜欢的圆润或“猫爪”轮廓可作为品种个性或少量变体保留。自然化优先调整搭接、姿态、根部承接，不把所有作物都改成写实叶簇，也不向所有物种推广同一种可爱团冠。
- 植物可以独立制作，再由菜地、槽架等组织。根点跟随地面，茎叶保持竖直；土地缩放优先调整株数与间距，不压扁或拉长菜株。交互与保存接入沿用场景资产技能，不在纯美术修改中扩展业务状态。
