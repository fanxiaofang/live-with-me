# Live With Me 美术资产制作

制作清晰、温润、材质可辨的原生 SVG / TSX。统一来自形体、光照、材质与细节主次，允许不同资产有自己的色域和轮廓语言；不要把所有植物画成相同的叶团，或把所有材料处理成同一种木色与亮边。

## 范围、参照与细节尺度

- 先确定用途、接地点、实际显示大小及本次允许修改的对象。默认保护丘陵、远山及其植被；草地／麦田的近处树仅在用户授权时调整。按实际调用层识别范围，文件名、共享组件和参考索引不构成额外授权；共享资产影响未授权图层时，在获准的调用处使用专属变体。
- 从 [资产索引](references/source-atlas.md) 选择能解释当前材质与相邻环境的参照，读对应源码并看场景或可靠截图。明确借鉴的部位和局限：旧资产不是整件合格样板，最新用户反馈优先于索引与历史注释。
- 根据实际用途分配细节，不设统一线宽或叶片数量：庭院主物可交代结构和少量微细节；建筑配景保留材质与遮挡；草地／麦田近树保留树种与主要枝叶层次；丘陵远树依靠剪影、色块和空气感。放大检查结构后，回到真实显示尺寸判断取舍。
- 动手前明确本次最应读出的结构特征，以及用户喜欢并要求保留的造型或配色。自然化可通过姿态、搭接与变体完成；不要顺手消除已有的可爱轮廓或扩大重绘范围。

## 造型、颜色与材料

- 先建立轮廓、承托、厚度和前后关系，再加纹理。使用邻近资产的局部轴向：主屋地板斜率约 ±0.283，项目并非统一 30° 等轴测。整组缩放保留接地点、人物比例与命中区。
- 新增或调整配色时读 [配色方法](references/color-design.md)。学习主体、受光、暗部和点缀的关系，允许新色相；主体色应有清楚的面积，不用浅色覆盖层或大块暗面淹没材料色。
- 画材质时按需读 [材质与线条](references/materials-and-lines.md)。色块分层不等于多边形折角：板材、石材可有利落硬边，枝叶、布料和软物用符合结构的曲面与遮挡。线条分轮廓、接缝、纹理与反光，避免统一黑边或连续白边。
- 树木、蔬菜、香草及成片植物按需读 [植物结构与品种](references/plants.md)。先确定生长结构与品种剪影，再处理颜色与纹理；在场景尺寸下分别判断整株、叶冠、花果及支架的比例。
- 土面、草土交接或多朝向资产按需读 [材质与线条](references/materials-and-lines.md) 的地面部分。共用投影不等于整件图形直接旋转；按可见体积判断是否需要重画肩面、遮挡与光照。
- 手作感来自有成因的不对称、折层、自然分叉及克制细节，不靠随机抖动、密集噪点或重复描边。渐变、投影与高光服务材质，不代替结构；模糊只用于独立影子或有依据的发光。

## 原生接入

- 沿用现有 React / SVG、`svgAction` 与图层约定，不为单个资产引入绘图库或位图替代。外层定位、内层几何与动画分离，避免 CSS transform 覆盖摆放 transform。
- 新增 gradient / clipPath / mask / filter 的 ID 按实例隔离。相同材料可复用 `TimberFloorMaterial`、`GroundShadow` 等；装饰节点不拦截点击。
- 保留现有拖动对象 ID、摆放锚点及存档；纯美术修改不扩展业务交互或存储结构。日暮夜沿用对象所在层的主题／环境契约，不重复套滤镜，不把环境变色误作季节或树种逻辑。

## 定向检查与交付

- 先在实际场景尺寸检查比例、主次、轮廓、遮挡和必要命中，再对具体疑点看局部。交接应可追溯：叶柄接枝、果梗接结果枝、藤接藤节，根部收进土面或容器；有摆动时只检查相关运动范围。
- 按 [视觉检查](references/visual-review.md) 选择必要视角，可复用其中的截图脚本。目标确实入镜、主题稳定且已看到新 DOM 后才截图；修改预览取景不写回正式相机。
- 小幅静态美术改动合并一次实际场景与必要局部复核，可使用可靠的当前截图；语法检查不替代视觉判断。工具与检查按具体风险选取，遵循用户当轮范围，不默认补测试、全套主题或重复类型检查；已覆盖本次风险且无具体疑点即结束。
- 报告具体变化、参照与实际检查；截图生成不等于视觉合格，用户未明确认可时不得标记为已认可。发现问题先改进检查执行，不把每个局部失误累积成适用于所有资产的规则。
