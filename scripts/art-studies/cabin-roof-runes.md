# 红陶瓦帽顶：护符刻纹与微光

日期：2026-11-09。当前为待用户评审版本。

## 目标与范围

保留已通过大体方向的四坡帽顶与赤陶配色，替换突兀的黄铜月片和三块蓝绿釉瓦。仅调整屋顶装饰；木屋主体、布局、存档与交互沿用原实现。

## 调研与借鉴边界

- [Historic England：What Are Witches’ Marks?](https://historicengland.org.uk/whats-new/features/discovering-witches-marks/what-are-witches-marks/)
  建筑保护刻痕通常与石材、木构及入口部位结合。借鉴“刻入承接材料”的关系，不把本次五个符号宣称为同一历史传统，也不把所有历史刻痕的解释视为定论。
- [PlayStation / Santa Monica：God of War Ragnarök concept design](https://blog.playstation.com/2023/01/26/from-concept-art-to-cosplay-creating-iconic-characters-for-god-of-war-ragnarok/)
  文章说明锤头与斧刃的刻入式符文树如何建立视觉联系。借鉴纹样与器物一体、同一材质语言的原则，不复制其字形、武器纹样或强烈战斗光效。
- [ESO：Venus cycle](https://www.eso.org/public/outreach/eduoff/vt-2004/Education/edu1app5.html)
  金星相对地球的约八年周期具有五重关系；本次五瓣图案依据用户提供的视觉参考简化，并非精确轨道绘图。
- [British Museum：Hand of Fatima / khamsa pendant](https://islamicworld.britishmuseum.org/collection/RRM46563)
  确认手形护符作为器物装饰的实例；Hamsa 并非本次其他月相符号的同源字母。
- [MDN：SVG Gaussian blur](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/feGaussianBlur)
  滤镜默认在线性 RGB 空间处理，须明确色彩空间和滤镜范围。当前微光采用 sRGB，清晰核心与模糊光分层。

三月相按用户提供的月盈月亏图形绘制；五角星保持正置；金星花提取五瓣交织特征。手掌护符与升女符作为浅刻纹，后者按用户提供的现代图案理解，不描述为古代符文。各种象征的意义会随传统与语境变化，本项目不设置一套通用宗教解释。

## 第一轮设计（历史记录）

三月相位于正面帽冠中段，是唯一高亮主纹。金星花和圆环正置五角星分布在下方，尺寸与亮度均下降。Hamsa 位于侧面，升女符位于较高处，主要作为近看才能发现的浅刻纹。统一使用陶土刻槽、窄边反光和柔和的月白草绿色光芯。

白天主要显露槽口；黄昏微光很弱；夜间三月相与两个次级符号发出有限微光。无连续动画、漂浮粒子、整圈发光屋檐或额外灯光系统。

## 矢量 / 2.5D 实施约束

1. 原生路径，不使用 Unicode 字体或位图贴花。图形只保留辨识所需的线与留白，不复制嵌套五角星等易糊细节。
2. 按真实帽顶 `hatPoint(angle,t)` 采样投影，包括长直线的中间采样；不把平面徽章单纯旋转后贴在屏幕上。
3. 刻槽暗线、轻微偏移的材料亮边、窄光芯、模糊光分别绘制。发光关闭时仍有刻纹；模糊不作用于整个符号或屋顶。
4. 统一表面裁切限制，避免符号和光跑出帽沿。滤镜留足局部区域，避免出现直线切光；资源 ID 按实例隔离。
5. 不使用 screen/add 混合或纯白粗线，把红瓦洗成灰白。小图保持主次，不用统一增粗所有纹样提高可见度。
6. 装饰不拦截点击，不修改庭院对象 ID、位置、保存关系。微光在 SVG / CSS 层处理，不增加 JavaScript 逐帧采样。

源码：`src/components/architecture/RoofRuneEngravings.tsx`；屋面投影与挂载：`WoodenCabinHaven.tsx`。

## 第二轮：护符弧带与陶瓦反光

用户认可的下一步为重新组织构图、加强刻槽、补主符文附近反光。三月相、金星花和正置五角星改为沿同一条跨坡面曲线布置，间隔若干短弧，保留图案之间的空隙；侧面的 Hamsa 与高处的升女符继续独立且更浅。未增加节点、点阵、粒子或动画。

侧面符号不再被归一化成与正面同样的表观宽度。所有刻纹与短弧仍沿帽顶表面采样。刻槽改为红褐槽心和窄的暖陶边缘，日间芯线降低灰黄感；夜间主符文使用月白光芯、窄灰绿外溢光，并将低强度暖橙反光限制在它附近的瓦面。反光在刻槽和清晰光芯之前绘制，避免覆盖边缘与改变整片屋顶色彩。

## 第三轮：让魔法产生可见的表现（待评审）

用户对第二轮的反馈为“没有魔法奇幻的感觉”。整齐排列与克制微光仍主要呈现普通保护刻纹，因此这一轮不再只微调线条组织。

放大主三月相的局部分量，增加暖月白与浅绿之间的细微光色变化，增强刻槽外溢光及邻近陶瓦的反光。黄昏和夜间出现三处极小悬浮微光，其中一处有短而弯曲的离面光迹；主光晕约七秒缓慢明灭，微光约六秒微量漂移。图形核心不跟着模糊，不增加全局灯光或漂浮法阵。

动画仅在 `prefers-reduced-motion: no-preference` 下启用，使用 CSS opacity / transform，不增加 JavaScript 帧循环。悬浮光独立于屋面裁切，刻纹及反光继续受屋面裁切约束，避免将“离面光”与“刻纹越界”混为同一层。

## 第四轮：四种独立祝福（待评审）

用户认可当前主三月相效果，要求其余四个符号各有与寓意相关的表现。本轮保留三月相的尺寸、光芯、外溢光与原有呼吸节奏。

- 升女符：中央刻线先向月牙汇光，邻近刻线随后响应；月牙亮起后放出一枚上升的小光种。
- Hamsa：掌心先亮，轮廓出现流光，然后一小段弧罩沿手掌外侧展开、退去。无眼睛眨动或完整泡泡护罩。
- 金星花：五瓣错开泛光，花心随后聚光，形状不旋转。
- 正置五角星：五个尖端依次响应，随后外圆描亮并短暂闭合，保持正置与保护印的稳定感。

四种动作共享 32 秒周期，启动相隔 8 秒，各自约 5 秒活跃，其余时段退回浅刻纹。光迹仍沿真实帽顶投影；手掌与升女符适度增大以容纳动作，主三月相未改。白天特效强度仅为夜间约 12%，黄昏约 45%。减少动态效果时四种动作静止且降低为浅亮状态。

`public/art-studies/cabin-wards/index.html` 是从当前实际 DOM 导出的独立夜间预览快照，包含自然循环及四个定格按钮，便于检查动作与主次。该快照用于本轮记录，后续源码变化不会自动更新它。导出长 SVG 时分段读取，避免内容被传输截断；不要将残缺预览误判为场景实现缺失。

## 第五轮：精简小木屋、将祝福分配给不同建筑

用户同意小木屋只保留三月相、升女符和 Hamsa，并要求将五角星及其效果移到羊圈雨棚，金星花放入大木屋。当前分布为：

- 小木屋：仅三种刻纹，移除原来连接另外两种符号的短弧，主三月相效果保留。
- 羊圈：五角星位于雪松雨棚坡面中央，按照屋面长边与坡向投影，保留五点响应与外圆闭合效果，随羊圈移动。
- 大木屋：金星花位于阅读阁楼的木地板，顺着地板轴向作浅刻纹；保留逐瓣点亮、花心聚光效果，位于前方栏杆和地板收边之后的正确遮挡层。

三处共享原生图案与动画代码，通过独立实例选择承载的图案。滤镜范围跟随各自图案坐标计算，资源 ID 隔离；小木屋的主符文过滤范围与光效保留。没有新增 YardId、偏移存档或交互命中，原父建筑的摆放和保存继续生效。

原五符号独立预览改标为分布调整前的历史小样；本轮结果以主场景为准。

## 第六轮：日间材料与墙面金星花（待评审）

用户指出阁楼后续会放置家具，不适合作为金星花的长期承接面，并认可墙面方案。本轮将其移到工作区窗户上方的暖灰泥墙，避开窗帘杆、工具板与干花束；不新增徽章底板，而以矿物浅金填色、窄槽口和少量瓣内色面表现浅刻。轮廓沿左墙约 -.285 的水平轴投影，保留逐瓣聚光效果，彻底移除阁楼地板图案。

三月相所在瓦行改为一块略宽的弧形陶瓦，保持原屋面曲率，柔和的暖赤陶色差、搭接边和少量边缘磨损使其在白天也可辨认。Hamsa、升女符提高日间刻槽与填色辨识度，不新增各自的圆盘或徽章。

雨棚五角星放在一块顺坡铺设的宽雪松木瓦上，用宽缓木色渐变、顺纹刻线、短边缘磨损表示加工关系。避免密集噪点、污渍晕圈与无依据裂纹。木瓦上的保护印按木材色组处理，夜间保留原五点与闭圆效果。

新增墙面资产 `CottageVenusWard.tsx` 挂在主屋工作区内，随主屋保留既有摆放与交互；没有新增庭院物件 ID。

## 第七轮：撤销补片、强化原材料内的刻槽

用户否定第六轮的宽陶瓦与宽木瓦：明确轮廓和底色使它们看起来像贴上的补丁。参考图要求符号沉入原有屋面，原瓦缝、木纹与受光应保持连续。本轮删除两块补片及其专属渐变、边框、磨损图形，保留原屋面；仅在符号笔画的尺度内加强槽心暗边与下缘窄亮边，夜间反光仍局限在符号周围，无额外封闭底板。

用户同时否定米色墙上的同色系浅金边与靠近墙顶交界的位置。金星花移到窗户右侧、干花束左侧的墙面留白，使用灰绿色槽边与浅绿矿物填色，远离屋顶交接，保持原逐瓣光效。实际场景中核对了窗框、工具板与干花的相邻位置，确认两处补片节点均已移除。
